# 方块属性规范与对照表

核对日期：2026-10-20。适用 Minecraft 1.21.1、当前锁定的 Sable 2.0.6、Deep Seas 3.3.0。

本文件先定义目标，不代表已实施。铁质潜艇壳当前仍是 v0.1.5 的实现。本轮不改代码、Mod 配置或存档。

## 铁质潜艇壳目标表

总体规则：**采集行为参考铁块；原版防护属性及适用的第三方物理、耐压属性参考黑曜石；外观保持灰色金属。**

| 分类 | 属性 | 当前铁质潜艇壳 | 目标 | 实现位置/说明 |
|---|---|---|---|---|
| 标识 | 方块/物品ID | `dbv_world:iron_submarine_hull` | 保持 | 不能为了兼容把ID改成黑曜石 |
| 采集 | 挖掘硬度 | 50 | **5，铁块标准** | 注册属性 `destroyTime`；不要连带把爆炸抗性改成铁块 |
| 采集 | 有效工具 | 镐 | 镐 | `minecraft:mineable/pickaxe` |
| 采集 | 最低工具等级 | 钻石级 | **石镐及以上，铁块标准** | 从 `needs_diamond_tool` 移除，加入 `needs_stone_tool`；金镐不满足 |
| 采集 | 是否要求正确工具才能掉落 | 是 | 是 | `requiresCorrectToolForDrops` |
| 采集 | 掉落 | 正确工具掉落自身 | 保持；时运不增加掉落 | 方块掉落表，不掉铁锭或黑曜石 |
| 采集 | 实际挖掘耗时 | 随工具/状态变化 | 同工具同状态下与铁块一致 | 不写死秒数；效率、水下、挖掘疲劳等会影响 |
| 原版防护 | 爆炸抗性 | 1200 | **1200，黑曜石标准** | 保留 `explosionResistance`，不是铁块的6 |
| 原版防护 | 活塞推拉 | 不可 | 保持黑曜石标准 | `PushReaction.BLOCK`；不等于禁止航空学物理船移动 |
| 原版防护 | 末影龙破坏 | 免疫 | 保持黑曜石标准 | `minecraft:dragon_immune` |
| 原版几何 | 碰撞、遮光、形状 | 完整实心立方体、不透明 | 保持 | 不发光、不可含水；不是半砖/薄板 |
| 视觉 | 贴图 | 64×64灰色金属、边缘螺丝接缝 | 保持，六面相同 | `cube_all` |
| 音效 | 放置/破坏脚步声 | 黑曜石的石质音效 | 暂保留 | “采集像铁块”在此解释为硬度与工具，不自动扩大到声音；可后续单独指定金属声 |
| Sable/航空学 | 单块质量 | 未显式适配；无额外覆盖时走默认1.0 | **2.0，黑曜石标准** | 黑曜石在 `sable:heavy` 标签中；该标签由物理属性JSON映射到 `sable:mass=2.0` |
| Sable/航空学 | 体积属性 | 未显式适配 | **1.0** | `sable:volume` 默认值；完整方块，不是额外浮筒 |
| Sable/航空学 | 碰撞摩擦 | 未显式适配 | **1.0** | `sable:friction` 默认值；与原版脚下摩擦字段分开 |
| Sable/航空学 | 碰撞回弹 | 未显式适配 | **0.0** | `sable:restitution` 默认值 |
| Sable/航空学 | 易碎标记 | 未显式适配 | **false** | `sable:fragile`；不代表绝对不会被任何方式破坏 |
| Sable/航空学 | 惯性 | 引擎计算 | 按与黑曜石一致的质量、几何规则计算 | 惯性取决于放置位置和船体形状，不给整船写固定值 |
| Sable/航空学 | 特殊漂浮材质 | 未配置 | 无，保持黑曜石标准 | `floating_material` 默认空；不额外增加升力 |
| Deep Seas | 材料耐深 `maxWaterDepth` | 未显式适配，由自动推算/已存配置决定 | **500格，当前黑曜石配置** | `config/submarine_hull.json` 或兼容层显式绑定 |
| Deep Seas | 压溃概率参数 `implosionChance` | 未显式适配 | **0.06，当前黑曜石配置** | 是上游内部判定参数，不是每秒6%或整船沉没概率 |
| Deep Seas | 全局深度/概率倍率 | 随上游配置 | 与黑曜石使用同一套运行倍率 | 当前分发配置两项倍率均为1.0；不修改全局算法 |
| Deep Seas | 密闭/进水判定 | 完整方块，尚无专项实测 | 作为实心外壳参与同一套检测 | 密闭是整舱条件，不是给单块添加“永远密闭” |
| 本项目 | 船体扫描、独立备份 | 通用方块路径 | 继续记录自身ID、状态、位置 | 不能在备份中伪装成黑曜石，否则恢复会换方块 |
| 本项目 | 创造分类/配方 | 深蓝远航分类；无配方 | 保持 | 配方另行设计 |

Sable数值来自安装包内原始标签、物理数据和默认值，表示基线目标；未执行新方块与黑曜石的运行时逐项对照。资源包/数据包或其他Mod覆盖后，应以同一世界中黑曜石的最终值为准，不能把2.0理解为现实公斤数。

## 已查明的适配差异

1. `Properties.ofFullCopy(Blocks.OBSIDIAN)` 只复制原版属性，不会复制其他Mod通过ID、标签和配置赋予的行为。
2. Sable通过 `sable:heavy` 标签识别黑曜石，当前铁质潜艇壳未加入。后续应显式适配质量，并检查最终物理属性；不要把新方块加入所有“黑曜石”物品标签，避免意外参与黑曜石配方或传送门等逻辑。
3. Deep Seas黑曜石静态默认值为500/0.06，本机 `runtime/client/config/submarine_hull.json` 也为500/0.06。自动计算普通新增方块时则依赖硬度、爆炸抗性和声音，且受默认400格上限限制。该自动计算上限不能直接解释为所有已配置材料都会被裁到400。
4. 改为铁块硬度后，不能继续依赖Deep Seas自动推导耐深。需明确映射到当前黑曜石的材料参数，并处理已有配置、服务端缓存和客户端同步。只给新世界默认配置写一行不够覆盖旧环境。
5. 耐深500不保证整船能安全下潜500格；门、玻璃、设备、连接和其他外壳块仍各自参与判定。也不应把整船重量、压载能力或航速作为单块属性照抄。
6. “其他Mod跟黑曜石一样”以有关船体材料的属性为范围；尚未检查到的附属专属行为应标记待核对，不能宣称全部Mod所有行为已继承。

## 后续新方块登记模板

| 必填项 | 记录内容 |
|---|---|
| 身份 | 唯一ID、中英文名、用途、引入版本 |
| 外观 | 纹理路径/尺寸、六面映射、模型、透明/发光、声音 |
| 采集基准 | 参考方块、硬度、工具类型、最低等级、掉落、时运/精准采集 |
| 防护基准 | 爆炸抗性、活塞反应、实体破坏免疫、燃烧行为 |
| 形状 | 完整方块/半砖/阶梯、碰撞体、含水、密闭贡献 |
| 物理基准 | 参考方块、质量、体积、摩擦、回弹、易碎、浮力特例、惯性计算方式 |
| 耐压基准 | 参考方块、耐深、压溃参数、全局倍率、配置覆盖优先级 |
| 获取方式 | 创造分类、配方/战利品/交易；未定就写未定 |
| 数据兼容 | 独立备份字段、旧版本迁移、ID是否稳定 |
| 证据与状态 | 对应Mod版本、资源路径/接口、基线值、运行时实测值、未验证项目 |

建议以后采用分开的“采集参考”“防护参考”“物理参考”“耐压参考”，避免一个父方块属性改变时连带改变所有系统。

## 实施后的验收

- 同工具、同状态分别挖铁块和新壳块，验证采集速度及木/金镐无掉落、石镐可掉落。
- 运行时读取黑曜石与新壳块的Sable物理属性、Deep Seas耐压参数并逐项比较。
- 分别在已有配置和全新配置下启动，检查配置同步与保存重进后的值。
- 使用形状相同的黑曜石船体与新壳船体对比质量与舱室判定；备份/恢复后仍为新壳方块。
