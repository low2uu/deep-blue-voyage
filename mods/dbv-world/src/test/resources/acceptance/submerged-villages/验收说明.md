# 淹没村庄验收

使用 Java 21、项目锁定的 1.21.1 NeoForge 依赖。临时客户端目录中复制正常开发配置，仅放置本目录的 client.js、server.js 至对应 KubeJS 脚本目录。目标 `saves/DBV-Villages` 必须不存在，且先清除该临时客户端上次的 `kubejs/village-done.json`，避免读到旧报告。

通过临时 Gradle init 文件，把本目录加入 main Java 源目录，并把 runClient 的 gameDirectory 指向临时客户端。该临时注入只用于 runClient；之后运行常规 build，确保正式 JAR 不包含 dbv/acceptance。

客户端脚本从空目录创建固定种子的深蓝远航地图，服务端逐区块生成两处历史海面村庄，检查建筑、道路、填水和起始岛。`kubejs/village-done.json` 必须 passed=true 且无 error；Gradle 成功退出本身不代表验收通过。完成后自动保存并关闭该测试客户端，不操作正式存档。

覆盖范围：同种子两个已知故障位置的全构件包围盒，加外围一圈区块。未声称检查所有种子、模组村庄或旧结构自动迁移。
