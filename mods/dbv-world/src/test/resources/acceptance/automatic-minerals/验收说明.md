# 自动矿种验收

将 MineralProbe.java 作为临时 main 源目录注入 runClient，gameDirectory 指向空的临时客户端。复制正常配置与本目录 client.js/server.js 到其 KubeJS 脚本目录。目标 saves/DBV-Minerals 必须不存在，先清除旧 done JSON。

首次检查新世界 10 种矿物、最近三岛、边界外地形。然后换成 reload-client.js/reload-server.js，快捷进入同一个 DBV-Minerals，检查快照重用、原有矿石保留、主艇加载及密封和起始岛建筑。只有 passed=true 且没有 error 才通过。所有逻辑只在测试客户端运行，不对已有用户世界运行。

当前测试的 10 种预期集合针对本仓库锁定的模组组合。增加模组后应按实际扫描证据更新测试预期，而不是修改扫描器的矿种名单。常规 build 不包含这些验收 Java 类。
