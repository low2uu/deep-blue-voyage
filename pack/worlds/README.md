### 深蓝远航-联合开发.zip.001～.004（v0.1.2，2026-10-19）

包含起始岛、船坞海床缓坡、当前主艇、3 个主线钻石占位地点、24 座支线矿岛。岛内单矿种矿脉包括机械动力锌矿。海面 Y=128，最低 Y=-256；已生成全部支线岛及主线标记所需区块，其余范围内海域按探索生成，暂时限制在中心边长 10000 格的正方形内。

完整压缩包约 149 MiB，分为 4 卷保存，使用 `world-manifest.json` 校验完整性。拉取完整仓库后，在项目根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\restore-world.ps1
```

脚本自动合并、校验并导入至 `runtime/client/saves/`，已有同名存档时会拒绝覆盖。只校验不导入可加 `-VerifyOnly`。不要单独解压某一卷。更新 develop 并重新构建、重启客户端。本机选择“深蓝远航·联合开发”。不要覆盖合并自己的游玩进度。地点坐标与验证记录见[随机主线与矿脉支线岛](../../docs/development/随机主线与矿脉支线岛-v0.1.2.md)。
