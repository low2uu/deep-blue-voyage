## 当前交付

### 深蓝远航-联合开发.zip.001（v0.1.4，2026-10-20）

按用户授权从空目录重建的联合开发存档，包含起始岛、船坞和新版初始潜艇，以及自动矿种快照。当前识别 10 种矿石/宝石；最近三岛为铁、铜、金，其他岛屿随机。保留原有天然矿物。

海面 Y=128，最低 Y=-256；中心 10000 格外也按同一世界种子生成相同规则的区域和资源岛，没有原先的探索边界。仅生成出生点及验收所需的局部区块，其余按探索加载。

压缩包约 21.2 MiB，本版只有一卷 `.001`，仍由 `world-manifest.json` 和导入脚本统一校验。不要混用旧版分卷。拉取完整仓库后，在项目根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\restore-world.ps1
```

脚本自动合并、校验并导入至 `runtime/client/saves/`，已有同名存档时会拒绝覆盖。只校验不导入可加 `-VerifyOnly`。不要单独解压某一卷。更新 develop 并重新构建、重启客户端。本机选择“深蓝远航·联合开发”。不要覆盖合并自己的游玩进度。生成规则与验收见[自动矿种与无限探索](../../docs/development/自动矿种与无限探索-v0.1.4.md)。
