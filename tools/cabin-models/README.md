# 舱内设备模型生成

在仓库根目录依次执行 `python tools/cabin-models/generate.py` 和 `python tools/cabin-models/finish.py`。需要Pillow、NumPy；使用已有物品模型工具的原生立方体模型导出和离线深度渲染，不启动Minecraft。预览字体为Windows微软雅黑。

生成控制台、显示器、人员舱门、大舱门核心与结构板的模型、门状态资源、双语名称、掉落和完整设计规格。共用项目已有128×128调色材质；模型及开关状态由原生方块资源表示。大门开门无碰撞，视觉表现为收起，尚无滑轨动画。

请同时更新操作文档和状态实现；不要仅通过改模型修改气密规则。核心与结构板需一个核心、六面连接、朝向一致；人员门为1×2。气密由锁定和开闭状态共同决定。
