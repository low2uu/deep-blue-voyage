# 深蓝远航内容设计器 · 便携版

**先完整解压ZIP，再双击 `index.html`，用Chrome或Edge等现代浏览器打开。** Windows也可以双击 `start.cmd`。不要只提取HTML，其他JS/CSS文件必须保留在同一目录。

无需安装Java、Node、Python、Minecraft或整合包，无需联网、账户或服务器。普通使用不需要执行任何命令。

## 怎么填写

1. 点击“新建设计”，或者“载入铁质潜艇壳预设”。
2. 在左侧选择分类。需要填写的属性，将状态改为“明确指定”；未决定的保留“待设计”，不涉及的选“不适用”。
3. 填写中英文名称、注册ID（如`dbv_world:my_block`）、类别、功能描述及各项属性。
4. 点击“检查填写内容”，处理错误。点击“导出开发规格JSON”，把下载的JSON发给开发者。
5. 暂时没填完时，点击“导出草稿JSON”；下次用“导入JSON”继续编辑。

包含14类147项属性及扩展需求，覆盖采集、防护、航空学、深海学、功能交互、配方、接口、独立备份和验收要求。所有字段都会导出；待定项不会悄悄变成默认值。

## 保存与分享

- 下载位置由浏览器设置决定，通常在“下载”文件夹。
- 浏览器本地草稿只是辅助，不能代替导出的JSON。换电脑、换浏览器或清理缓存前先导出。
- 整个便携目录可以复制给别人；分享需求时发送导出的JSON即可。
- 工具只编辑需求，不修改游戏或存档，不直接生成可运行的Mod。
- 铁质潜艇壳预设是设计目标，不代表游戏已经实现全部参数。

## 包内文件

| 文件 | 用途 |
| --- | --- |
| `index.html` / `start.cmd` | 页面 / Windows启动入口 |
| `app.js`、`catalog.js`、`core.js`、`style.css` | 必需的页面程序与样式 |
| `iron-submarine-hull.example.json` | 可直接导入的完整示例 |
| `content-spec.schema.json` | 提供给开发者的格式校验规范 |
| `manifest.json` | 包版本与每个文件的SHA-256校验值 |
| `validate.cjs` / `test.cjs` | 开发者可选的命令行校验与测试，需要Node |
| `docs/` | 完整设计说明、字段目录和属性对照表 |
