# v0.1.13 后台运行测试

日期：2026-10-22。代码提交：020c3b1，develop 分支。Minecraft 1.21.1 / NeoForge，完整开发客户端依赖。

结论：本轮构建、地图生成、模型渲染、实体短时运行、存档重进和潜艇资格检查通过；仍存在第三方模组非致命日志问题，不能据此认定整个整合包无缺陷。

## 测试方式

将已交付 v0.1.4 地图导入独立目录 `.local/latest-v0.1.13-20261022`，以最新 v0.1.13 代码运行，再保存并重进。正式存档未修改。本轮没有从创建世界界面新建种子，测试的是旧交付存档升级加载及未生成区域的按需生成。

临时验收 Java 源只注入测试启动任务；结束后重新进行正式构建，避免测试类进入交付 JAR。没有修改正式源代码或既有文档工作区，也没有提交版本。

## 发现的问题与限制

1. 交付存档为和平难度，守卫者等敌对基底原型会被自动清除。首次实体检查因此失败；仅将测试副本改为普通难度后，15 种实体均运行通过。以后使用刷怪蛋或测试战斗时应选非和平难度。正式存档难度未改。
2. 交错电网本机原生加速后端加载失败，日志明确提示加速求解器不可用；本轮未验证其电网负载性能。
3. 柴油动力 `createdieselgenerators:blocks/andesite_girder_strut` 掉落表引用缺失物品，解析失败；本轮未修复或验证该相关方块掉落。
4. 还出现 wdutils 访问转换文件缺失、JEI 收到创造分类空物品，以及第三方占位模型缺失等日志；未阻止进入世界，但尚未逐项定位。地图更新检查曾超时。
5. 航空学蓝图捕获有部分方块实体依赖枚举警告，最终仍记录 1 个子空间、317 个方块实体、1 个运行中机械结构并保存成功；不等于全部机械运动行为都已验收。
6. 未验证多人连接、独立服务器、长期运行、潜艇巡航与战斗；新增武器功能、怪物专属技能和 Boss 阶段仍属于未实现内容。
