# 验证证据与历史输出

这里保存各次开发的报告、日志、截图、测试数据和一次性验证程序，按原批次留存。它们证明的是对应提交和当时配置下的结果，不是当前安装包或日常启动入口。最新使用方法见[部署文档](../docs/部署启动与版本更新-deployment-launch-update.md)，当前依赖见[Mod清单](../docs/当前Mod清单-current-mod-list.md)。

本次整理保留全部路径，供游戏机制及历史文档继续引用。不要直接执行旧批次中的JS、Java或Python程序来更新正式世界；其中包含当时的坐标、存档路径和迁移假设。
