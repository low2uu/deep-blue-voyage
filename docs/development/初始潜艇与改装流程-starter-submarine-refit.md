# 初始潜艇与改装流程

适用：Minecraft 1.21.1 / NeoForge 21.1.259 / Sable 2.0.6 / Deep Seas 3.3.0。开发阶段 M1.2，使用同一个正式开发客户端。此版是船坞建设样艇与有限范围改装流程，不是可出海的生存潜艇成品。

## 初始艇

新建“起始岛”预设世界时记录初始艇生成请求；建设模式启动后，在船坞 `(60,68,150)` 至 `(68,74,164)` 生成 9×7×15 的小艇。包括铁制船壳、玻璃观察窗、地板、顶部舱口、照明、船载电脑、电解器、氧气扩散器和红石供电。系泊使用 Sable 局部固定约束，不暂停整个世界物理。

船坞提供明确的建设岸供：向电解器供水、供 FE，并向扩散器直接补充氧气；电解器本身仍按 Deep Seas 逻辑产氧。该便利机制仅作用于初始艇、仅在船坞范围及建设模式内运行，不证明管路连通或自持航行能力。没有安装推进、武器或 AI 船长。

初次验收使用临时 Sable 加载票据，登记后释放，不常驻加载远海。待真实 Deep Seas 密闭扫描和氧气启动完成，使用同一三条件检查登记唯一“酒狐号·初始艇”。生成请求、生成中标记、船体 ID 分开保存；已登记、已存在载体、泊位非空、生成中断等情形均停止，不盲目复制新船。老世界不会因更新 Mod 被自动覆盖。

## 玩家流程与界面

1. 本机已准备 `runtime/client/saves/DBV-Island-v2`，游戏中名称为 **Deep Blue Voyage - Starter Submarine v2**。原 `DBV-Island-v1` 保留。也可新建起始岛预设世界。使用 `tools/dev.ps1 run` 启动，保持 `config/development-session.json` 中建设模式开启，以创造模式管理员进入船坞。
2. **潜行右键船载电脑**：聊天区显示设备报告、船坞状态，以及可点击的 **开始改装 / 检查 / 提交 / 取消并还原**。普通右键仍使用 Deep Seas 原有界面。
3. 开始改装前检查资格、距离、船坞位置、系泊状态、唯一身份和其他开发者占用情况，随后把原船方块和支持设备的数据写入独立备份；写入成功才允许编辑。
4. 首版限制在开始时原船包围盒内，不能拆系泊角块，不能扩容。可换铁、玻璃、深板岩、石材、混凝土、铜块、舱口、照明、红石块和三个核心设备。容器、线缆、武器、运动机械、子船及实体不在本次快照覆盖范围。
5. 点“检查”可随时查看三条件及原因。点“提交”后若扫描尚未完成，暂时锁定编辑，自动等待最多 200 tick；通过后保存，失败或超时则还原。取消会直接还原，包括清掉原本为空气位置上的新增方块。
6. 未提交就退出游戏，下次加载原艇时自动回滚。活动备份或登记损坏会阻止改装，不尝试创建新身份。主艇永久 ID 始终保留。

命令入口：`/dbv refit`，以及 `/dbv refit begin|check|commit|cancel`。当控制器被拆下时，仍可通过命令取消和恢复；命令同样检查创造模式、权限、距离和事务所有者。

界面当前为**可点击的聊天菜单**，尚未实现独立图形改装面板、空间高亮、材料购物清单或酒狐对话。提示内容由服务端生成，菜单按钮不绕过资格与权限检查。

## 数据和恢复边界

存档中的 `dbv/fleet/dock/`：

| 文件 | 用途 |
| --- | --- |
| `starter-request.nbt` | 新世界生成请求 |
| `starter-building.nbt` | 生成开始标记，保留以识别中断 |
| `starter.nbt` | 初始 Sable 船体 ID、系泊锚点 |
| `active-refit.nbt` | 当前不可覆盖的改装前快照，含身份、所有者、边界、每格状态及支持方块实体 NBT |
| `history/*-committed.nbt` | 成功提交后的旧快照 |
| `history/*-cancelled/rejected/interrupted.nbt` | 取消、失败或中断后已完成恢复的快照 |

快照以临时文件写入、强制落盘、原子重命名发布。恢复在同一个 Sable 船体中进行，不创建第二艘艇。完成世界保存后才归档活动快照；恢复途中再次退出，下次仍从活动快照重新恢复。不要手动删除这些文件来“解锁”。

覆盖范围为固定版本、有限方块白名单的 **BODY_ONLY**。不包括任意 Mod 的外部状态、实体、Power Grid 连线、管网连接保证、乘员、灾难损毁或主艇丢失后的重新部署。创造模式避免生存材料回滚复制；生存资源托管与消耗结算需要后续单独实现。管理员 WorldEdit、外部脚本或其他绕过普通放置事件的工具，不属于本版编辑保护范围，改装期间不要使用。

## 验收

使用正式客户端及原岛存档副本，临时脚本见 `mods/dbv-world/src/test/resources/acceptance/refit-server.js`；测试资源不进入主 Mod JAR。记录放在 `outputs/starter-refit-20261014/`。实际通过项以该目录日志和验证摘要为准。原 `DBV-Island-v1` 不修改。

验收结果（2026-10-14）：14 项单元测试通过；正式客户端首次流程 20 项、重启流程 16 项、新世界出生点距离流程 6 项断言通过。新世界测试从无区块、未初始化的起始岛预设开始，验证无需玩家靠近即可完成登记。

一次启动出现 Create 注册回调异常，重启后成功；保留错误记录，不宣称已彻底修复上游加载问题。临时自动操作脚本已移出运行目录，验收副本归档在 `runtime/backups/DBV-Refit-Acceptance`。
