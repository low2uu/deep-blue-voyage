# 酒狐号灯笼鱼型潜艇

目标版本：Minecraft 1.21.1 / NeoForge。设备按已安装的 Deep Seas 3.3.0、Create 6.0.10、Create Diesel Generators 1.3.15实现。

## 布局

整艇含外置传动、尾部气闸和声呐杆的包围盒为15×11×24（3960格），保留当前4096格改装上限。泊位范围 `(60,68,150)` 至 `(74,78,173)`，艇首朝北。船体用铁块形成收头、鼓腹和收尾的灯笼鱼轮廓，前窗采用 Deep Seas 铁制耐压玻璃 `create_submarine:iron_pressurizer`，额前弯杆顶端安装声呐。

| 系统 | 配置与连接 |
| --- | --- |
| 升降与平衡 | 底部四角各一组2×2×2压载舱，共32个压载方块。每组通过独立泵控制器和管道连接外露海水阀；中央控制器负责注排水指令，稳定行为使用Deep Seas现有物理逻辑。 |
| 推进与转向 | 左右各一个水下螺旋桨，各自通过传动轴、齿轮箱、离合器和换向器接入舱内柴油机。独立控制两侧的启停及转向。 |
| 柴油动力 | 两台独立柴油机、左右各一个柴油储罐。每罐初装16桶柴油，每台发动机另预充1桶启动油，供油泵持续从储罐补给。燃料真实消耗，未增加无限燃料脚本。 |
| 制氧 | 电解水装置的模块槽装入传动杆，由柴油轴系驱动其内置发电模块；水罐经机械泵补水，氧气经另一台泵输送至红石启用的氧气释放装置。 |
| 淡水 | 16桶储水罐，电解器另预充4桶水；属于有限储备，用完需补水。 |
| 舱室 | 驾驶与生活主舱、尾部独立水下出舱室。气闸具备内外铁门、面向舱室与面向外海的两个减压阀、机械泵与启停离合器。 |
| 信息与存储 | 中央控制器、舱内信息面板、箱子和木桶，继续接入主艇独立JSON归档。 |

升级不等于整艇达到玻璃标称耐压：铁壳、舱门与外露设备仍可能成为最弱点，以控制器实际诊断为准。

## 更新旧艇

新世界初始艇使用本模板。已有主艇不会在进入世界时被静默覆盖。建设模式创造管理员靠近仍系泊的主艇执行：

```mcfunction
/dbv refit angler
```

它先保存原艇与业务数据快照，再将原艇拆解并替换为新模板，保留主艇永久身份。原有容器及无方向物品能力中的物品迁移到新艇箱子和木桶；超过54个非空槽位时提前拒绝替换，需先整理。旧燃料、设备配置等仍保存在原艇快照中，不会自动映射到新设备。

检查完成后在中央界面提交，或执行 `/dbv refit commit`；取消用 `/dbv refit cancel`，恢复原艇。已有活动改装、未系泊或旧艇尺寸大于新模板时拒绝自动替换。已出航旧艇仍受现有返航系泊功能未完成的限制。

## 驾驶

出厂左右推进离合器均断开，中央控制器目标深度为0。机舱服务传动保持运行，因此停车也会消耗柴油。

1. 确认内外舱门关闭、柴油和水有余量，检查制氧、供氧和密闭状态。
2. 在主艇管理界面点击“出航”，解除建设用固定与岸供。尚未入水的螺旋桨不会提供水下推力。
3. 发动机前上方拉杆控制换向，侧壁凹位拉杆控制推进离合器。两侧同向可前进/后退，差速或反向可转弯；两台轴向螺旋桨不提供独立横向平移。
4. 中央控制器设置目标深度：目标更深时注水下潜，目标更浅时排水上浮。不要以改变整艇碰撞箱作为升降控制方式。

## 气闸使用

按上游思索的方式，先进入气闸并关闭内门，打开舱内启停拉杆，使泵从外海阀向舱室阀输水；完全灌满后停泵，再开外门离艇。返回时先进入气闸并关闭外门，用Create扳手反转气闸顶部可触及的机械泵朝向，启泵向海中排水；排空后停泵，再开内门。

当前Create普通机械泵按朝向决定流向，不能仅用齿轮换向器反转转速来切换注排水。四角压载使用的Deep Seas泵控制器则会自行按中央电脑指令改变抽送侧。气闸尚无电气门互锁，不能同时打开内外门。

## 依据与验证

参考已安装3.3.0版本资源中的 `ballast_vent`、`onboard_computer`、`decompression_chamber`、`electrolyzer` 思索说明，并核对 [上游思索源码](https://github.com/MaxCreateMC/Create-Deep-Seas/blob/3c287c5/src/main/java/com/maxenonyme/createsubmarine/submarine/ponder/SubmarinePonderScenes.java) 和 [泵控制器源码](https://github.com/MaxCreateMC/Create-Deep-Seas/blob/3c287c5/src/main/java/com/maxenonyme/createsubmarine/submarine/block/entity/PumpControllerBlockEntity.java)。Create泵的轴向及流向同时按已安装JAR核对。

验收记录保存到 `outputs/angler-submarine-20261015/`。验收使用原存档副本，与另一个任务的运行目录隔离；不修改正式地图。

2026-10-15 已验证：模板替换、原艇失败回滚、主舱392格密闭区域、物理装配后三项合格；双桨96/96转速和单侧换向后的-96/96；出航断开岸供20秒后电解器仍有4000毫桶水和10000 FE，三项仍合格。最终记录为 `final-acceptance.log`。构建及25项单元测试通过。

这不等同于完成全海试：四角压载已接入并验证传动，持续升降和平衡性能、气闸完整水下往返、续航和各深度耐压仍需后续海试。新世界自动生成采用相同模板，本轮验收重点是已有存档升级路径。测试日志中的早期失败保留用于排查，不能把失败后还原的旧艇合格结果当作新艇验收。
