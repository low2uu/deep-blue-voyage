# 淹没世界生成与开发边界

2026-10-16。Minecraft 1.21.1 NeoForge。

> 2026-10-19 更新：下文矩形保留区及临时基岩海床属于当时的迁移记录；现行近海规则与验收见[起始岛近海生成与验证](起始岛近海生成与验证-near-island-generation.md)。

当前开发存档采用“自然世界被海水淹没”的生成方式，海面Y=128，世界范围Y=-256～319。初始岛、建筑、船坞、油田和潜艇保留，岛外原来的建设用简单海床按探索重新生成。

## 生成顺序与效果

1. 以Minecraft 1.21.1主世界噪声与地形规则生成山地、平原、谷地、原有海底及地下空间，不将整个外海填成同一高度的平底。
2. 海面升至Y=128。水覆盖低地，仍高于海面的地形保留为陆地；露天低处的空气补水，地下含水层沿用正常生成系统，不把所有洞穴空气直接改成水。
3. 根据最终海床高度与原有气候，为淹没地表和水柱分配冷、暖及深浅海洋群系。地下深处仍可保留洞穴群系。
4. 使用最终群系的表层、特征和生态生成，包括海草、海带、暖海珊瑚等；生物按所属群系与正常刷新条件出现，不保证每个区块立刻刷出动物。
5. 已安装Mod通过其原有生成阶段、群系特征与生态接口参与。地形必须参与基础阶段的Mod不强行挪到最后；结构在游戏要求的阶段放置，生态依据最终环境生成。

实现文件为`FloodedWorldGenerator`和`data/dbv_world/worldgen/noise_settings/flooded_overworld.json`。噪声配置基于本机已安装Minecraft 1.21.1的主世界数据，调整海面和高度；不是自写几条正弦曲线代替正常世界。普通大陆地形不会保证固定海陆比例，仍可能保留较高陆地，之后需结合多个种子完善。

现有Mod中Deep Seas的深渊群系属于独立维度，本次没有将其直接复制到主世界；没有安装新Mod，也没有声称已经生成三大主线、海洋Boss或全部候选生态Mod。低于新海面的原陆地结构起点暂不生成，避免按新水面高度建立悬空陆地建筑；原海洋群系上的适配结构保持原有生成入口。后续Mod专属区域仍需逐项适配。

## 初始岛保留与过渡

完整保留X=-288～287、Z=-224～303范围的旧区块，覆盖建筑、油田标牌、船坞和出海口。该范围包含1188个不同生成阶段的区块；固定设施、船体虚拟空间、玩家和独立业务档案在离线转换时不重新生成。

保留区外设置192格平滑地形过渡，再接入正常噪声地形。保留区及过渡内部暂不挖新洞穴；邻区生成的树木、结构特征不能写入旧建筑区。保留区原有临时海床局部仍为基岩，这是迁移例外，不代表整个新世界的海床材质。

转换工具`tools/migrate-flooded-world.py`先建立完整ZIP备份，再复制存档；仅从副本中移除岛外旧占位区块及旧POI，使它们按探索生成。发现岛外方块实体、结构或普通实体会拒绝继续，避免删除未知工程。该工具只适用于已经检查过的v3建设存档，不是通用的任意地图重生成工具。

## 10000格临时开发范围

用户确认采用**范围内按探索生成，范围外暂时禁止探索与生成**。

- 以当前初始岛参考中心(0,0)为中心，设置10000×10000世界边界；方块坐标范围为X、Z各`[-5000,5000)`。
- 正常游戏移动由世界边界限制。管理员强制传送、第三方绕过边界的能力不作为允许探索范围。
- 生成器对范围外跳过地形、洞穴、结构、生态及初次生物生成，并拦截跨边界的特征方块写入；边缘区块只生成范围内部分。
- Minecraft为了邻区计算、光照或边缘缓存，仍可能建立少量范围外的空区块数据。因此“不生成”指不铺设范围外可玩地形与内容，不承诺磁盘中绝无范围外区块元数据。
- 不预生成整片1亿平方格区域。迁移只保留旧岛，实际验收按需载入少量远海和边缘样本。

此边界是当前开发阶段限制。1.0“主线范围之外仍生成同类区域但没有主线内容”的设定不变；公开版开放外海前需要移除临时生成裁剪与世界边界，并处理已经缓存的边缘空区块。

## 建设模式与潜艇

保留建设模式的开发性能设置、船坞停泊和岸供服务。淹没世界在建设模式下启用`doMobSpawning`，使海洋动物能按正常条件刷新；该规则也允许其他符合群系与难度条件的生物，并非只允许鱼类。袭击、幻翼等其余建设期开关仍按原建设模式处理。

项目最新提交已恢复Deep Seas原版浮力参数，本次不改回旧的浮力补偿。原艇处于出航状态时，在原版浮力下会下沉；迁移验收前通过既有停泊服务固定在船坞当前位置，避免地图生成期间继续下沉。停泊不代表已修复原艇自由航行时的浮力配平，出航前仍需另行配平。
