# 船坞海床坡度 — v0.1.1

2026-10-19，Minecraft 1.21.1 / NeoForge。

## 改动

新生成地形不再在船坞保护矩形边缘突然切换高度。以最近的船坞边缘海床为锚点，向外用 96 格平滑权重连接自然地形；船坞内部、建筑基础和出海净空保持原设计。

对当前存档采用一次性平滑修整：以实际海床高度为基础，固定船坞和外侧地形边界，沿最近边缘向外插值连接海床。岛上陆地和设施不参与修整。遇到箱子、刷怪笼、晶洞或其他未识别结构，保留其原始地形并增加六格保护余量，再重新计算坡度。修改前对整个计划范围进行检查，未通过检查时不写入地形。

一次性升级工具仅用于临时测试客户端，不随正式Mod加载。原存档在玩家保存退出后备份，后续以验收通过的副本交付。海面仍为 Y=128，世界底部 Y=-256，开发边界 10000 格不变。

## 版本约定

自研Mod、项目版本统一为 **0.1.1**。`AGENTS.md` 已记录用户要求：每次提交递增版本，提交标题以版本开头，创建并推送对应 Git 标签，不覆盖旧标签。历史开发版本 0.1.0 的提交编号保持原样。

## 证据

`outputs/dock-slope-v0.1.1/` 保存实机结果与一次性修整源码。新生成器的出口及左右两侧连续性由自动测试覆盖。

## 本次实测

修整 53861 个水下地形列。出口中心 X=64 的原接缝在 Z=303/304 附近从 Y=20 陡升到约 Y=115；修整后沿 96 格范围平滑过渡至 Y=76。全范围仍保留外围自然地形落差，不能把“出口平缓”理解成所有海床都变成均匀斜坡。

102080 项建筑、机器空间、船坞与出生点检查通过；新版潜艇仍为同一物理体、仅一艘，中央控制、供氧、密闭均合格并正常停泊。当前用户船体质量为 2579.25，保留本轮游玩后的修改，没有恢复成以前交付包中的旧船体状态。

修整前的完整本机备份为 `runtime/船坞坡度修改前-v0.1.0-完整.zip`。正式交付包仍为 `pack/worlds/深蓝远航-联合开发.zip`，版本由本次提交和 v0.1.1 标签标识。

保存后复进再次检查同一艘潜艇与船坞设施，出口逐格采样前显式加载所需区块，避免将未加载高度误判成平地。原生航行和浮力参数未修改。

最终复进实测出口中心 X=64、Z=303～399 的逐格海床高度差最大为 **1 格**，34 项自动测试通过。正式存档和交付 ZIP 均已更新；从旧客户端进入前需要完全退出并重新启动，以加载 0.1.1 代码。
