# 淹没村庄生成修复（v0.1.3）

## 确定的行为

海平面以下的原版村庄保留在实际陆地高度，被海水淹没。海平面仍为 Y=128，最低高度仍为 Y=-256。

村庄规划时原版使用 WORLD_SURFACE_WG，会把水面当作建筑和道路高度。修复在深蓝远航淹没世界的村庄规划期间，将该查询转换为 OCEAN_FLOOR_WG；贴地道路的重力处理也使用地面高度。原有以海平面筛掉低地结构的规则对村庄放行，对其他结构保持原行为。

建筑放置结束后，仅在村庄构件包围盒与当前区块交集内，将海面以下的空气填水、支持含水的方块设为含水。其他地下洞穴不受这一步影响。起始岛建筑、支线岛和主线占位仍按已有规则生成。

转换作用域使用线程隔离和 finally 清理，避免污染并行区块、普通世界和其他结构。

## 现有存档

检测到两处旧村庄起始区块：(38, 38)、(156, -26)，约对应方块坐标 (608, 608)、(2496, -416)。旧村庄中心底面均在 Y=127。

用户确认周边已有建设，因此**不删除、不下移、不重建这些旧村庄或周边区块**。本版本只修复后续新生成的村庄；已经保存的旧结构规划不会自动重新定位。现有联合开发存档及 Git 中 v0.1.2 的分卷存档保持原样。

完整退出游戏后重新启动开发客户端，即可加载新代码。已有存档在未生成过村庄规划的区域应用新规则；新地图选择“深蓝远航 起始岛”后直接应用。

## 验证

验收脚本位于 `mods/dbv-world/src/test/resources/acceptance/submerged-villages/`，仅作为测试源临时注入，不打包进正式 Mod。

采用与联合开发存档相同种子，从空目录新建地图，在两处历史问题坐标生成村庄及其完整覆盖区块，检查主体高度、道路、内部填水和起始岛建筑。普通 WORLD_SURFACE_WG 查询必须仍返回海面 128。另有线程隔离及嵌套异常恢复单元测试。

实际结果见 `outputs/villages-v0.1.3/验收结果.json`。

验收通过：312 个目标区块生成并保存重进；两处村庄中心底面分别为 Y=62、Y=54，与噪声地形首次空闲高度 63、55 对齐。村庄构件海面以下未剩余空气；95 和 90 个贴地道路构件得到检查。离线逐列复核道路投影范围，共 12,464 列的 Y=127 均为水，无浮在水面的道路残留。起始岛 102,080 项方块检查通过，40 项单元测试通过。

首次验收断言错误地要求沙漠村庄也有泥土小径；沙漠道路材质不同，已改为检查贴地构件、实际地面及海面残留，不以单一方块种类判断道路存在。
