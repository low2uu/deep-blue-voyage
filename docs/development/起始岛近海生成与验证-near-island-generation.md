# 起始岛近海正常生成与验证

> 本机存档已合并为“深蓝远航·联合开发”，旧本机副本已清理。见[联合验证与回退说明](潜艇地图联合验证与存档清理-combined-validation.md)。下文保留原阶段记录。

2026-10-19，Minecraft 1.21.1 / NeoForge。

## 本次规则

起始岛周围不再整体划为无生态建设海域。海面仍为 Y=128，最低 Y=-256，开发范围仍为中心 10000×10000 格、按需生成。

- 岛外恢复噪声地形、地表处理、洞穴、适用的结构和群系装饰；原有地下噪声、含水层与空洞不再被整列实心石头覆盖。
- 删除近海人工基岩海床。基岩仍在世界底部正常生成。
- 陆地岛体保留；近岸通过椭圆过渡接入自然海床，不再使用整块矩形平坦海床。
- 建筑地表、油田和船坞施工净空继续保护；正常海洋生态可以生成到岛附近，船坞不能被海草、结构等堵塞。
- 原有已生成区块不会因修改生成器自动更新。刷新工具只处理附近经检查仍为纯临时地形的区块，遇到方块实体、结构或非临时地形方块则保留。

## 存档刷新

关闭对应存档后使用 `tools/refresh-near-island.py <源存档> <新副本>`。工具拒绝覆盖目标目录，保留源存档，校验源文件未变、潜艇子层级、舰队档案、玩家和实体文件字节一致。筛选不能辨别玩家用石头、沙子等相同材料做过的改造，因此只应用于本次已检查的建设存档；其他存档应另行审计。该工具只支持已经使用淹没世界生成器的存档，不用于直接转换「新的世界5」等其他生成器的交付快照。

测试临时脚本和隔离源码放在 `.local` 下，不加入正式游戏的自动操作功能。测试记录放在 `outputs/near-island-20261019`。

## 范围说明

“正常生成”表示恢复当前已安装内容适用的生成阶段，不保证每种结构都出现在近海，也不把其他维度的专属地形直接搬进主世界。岛体和船坞的人工建设区域仍有必要的保护。旧建设期说明作为历史记录保留。

## 本次验收结果

本机 `runtime/client/saves/DBV-Island-v4` 已应用刷新，原档完整保存在 `runtime/world-archives/near-island-20261019/DBV-Island-v4-original`。只删除 665 个临时地形区块，让游戏按探索重生成；其余 3533 个区块的 NBT 内容一致，潜艇子层级、舰队档案、玩家、实体文件保持一致。测试过程中运行过的潜艇和玩家状态没有回写正式存档。

实际测试发现另一并行流程暂存源码并清理共享编译输出，前两次启动缺少生成器、第三次缺少验收类；随后改用完整隔离的临时源码和构建目录，第四次实机验证通过。正式工作目录恢复后已核对关键生成代码与测试版本一致。
