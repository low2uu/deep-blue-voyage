# 深蓝远航玩法设计

核心体验是建造并驾驶大型潜艇，把潜艇作为海底冒险的移动基地。世界以海洋为主，探索距离、海水深度和航道宽度需要适配潜艇，而非只增加海洋面积。

## 已确定的方向

- 以《海底两万里》式海底远航为主题。
- 支持玩家建造大型潜艇，并用于探索与冒险。
- 地形以海洋为主导，提供足够大的连续水域。
- 增加海洋群系，让不同海域具有可辨识的景观与探索内容。
- 增加海洋 Boss，作为海底冒险的重要挑战。

## 地形与潜艇的验证重点

潜艇长度、宽度、高度及操纵方式尚未确定，因此暂不锁定海底高度、海平面、群系尺寸或世界高度。先以实际潜艇原型测量所需空间，再确定世界生成参数。

| 项目 | 验证内容 |
| --- | --- |
| 连续海域 | 能否进行长距离航行，避免频繁被陆地截断 |
| 有效水深 | 船体上下是否留有足够通行空间 |
| 航道宽度 | 是否能通过海峡、绕开地形并完成转向 |
| 海底结构 | 遗迹入口与停泊区是否允许潜艇接近 |
| Boss 区域 | 是否具备符合战斗机制的活动空间 |
| 加载与性能 | 大型移动结构跨区块航行时是否稳定 |
| 多人联机 | 船体、玩家位置、交互与存档是否同步正常 |

## 待确定的玩法

潜艇推进与浮潜机制、舱内水体处理、能源与维修、氧气与压力、探索奖励、Boss 推进顺序，以及海面陆地比例。上述内容是后续设计议题，不代表已决定加入相应机制。
