# 版本记录

项目版本同时用于自研 Mod、提交标题与 Git 标签。正式发布目标 1.0 与当前开发版本分别记录。

## 0.1.13 — 2026-10-22

- 为 12 种普通怪和 3 个 Boss 制作专属分层模型、共享材质与基础关节动画，替换原版占位外观。
- 保留原型 AI、属性、掉落和守卫者攻击光束；潜水者支持手持装备显示，专属战斗技能仍待开发。
- 同步完整怪物设计 JSON、模型目录、离线预览和便携设计器；提供独立模型资料包。
- 编译与静态资源检查通过；按用户要求未启动 Minecraft 客户端或服务器，未实机验收动画及碰撞观感。

## 0.1.12 — 2026-10-22

- 为54个原型物品制作独立原生三维模型，替换原版借用图标；覆盖背包、手持、地面及展示框。
- 增加共享材质、几何源文件、离线模型总览和资源包；同步设计JSON与便携设计器内的规格。
- 内容生成器保留自定义模型引用，防止重新生成时覆盖为平面物品图标。
- 遵照要求未启动游戏测试，只做资源静态校验；怪物和刷怪蛋外观未修改，武器等使用功能仍待开发。

## 0.1.11 — 2026-10-22

- 新增54个原型物品、12种普通怪与3个Boss原型、刷怪蛋及掉落表；加入深蓝远航创造分类。
- 交付69份完整设计JSON，扩展设计器怪物字段与旧版JSON导入迁移，并更新便携工具。
- 使用原版临时模型和基础AI，暂不自然刷新；专属技能、武器功能、配方、Boss阶段和首杀奖励仍待开发。Boss目标生命保留，原型使用1024生命。
- 未修改正式地图、潜艇物理算法或独立备份机制。

## 0.1.10 — 2026-10-22

- 归档[整体玩法与数值初案](game-mechanics/整体玩法与数值初案-gameplay-and-balance-draft.md)，整理地区特色怪物、掉落、材料、升级与战斗数值。
- 明确已确认前提与待定设计、数值的边界，补充验证清单和游戏机制目录索引。
- 本次仅文档及版本标记变更，不修改游戏机制、配置、地图或Mod选型。

## 0.1.9 — 2026-10-20

- 联机方案改为固定昵称离线登录与 IPv6 监听，补充 IPv6 地址、TCP/UDP 放行及连接格式。
- 增加停服备份后应用配置与离线 UUID 白名单的命令，保留现有世界，说明身份切换的数据迁移边界。

## 0.1.8 — 2026-10-20

- 增加 server/ 联机部署、启动、完整备份、GitHub 更新及配套客户端导出脚本，默认正版验证与白名单。
- 初次导入联合开发地图，后续更新保留世界与配置；记录 Mod 哈希，提供停服回退流程。
- 修复 Deep Seas 材质反射在独立服务端访问客户端类导致的崩溃，保留原模组材质回退与压力/浮力算法。

## 0.1.7 — 2026-10-20

- 将内容设计器打包到`tool/content-designer/`，提供独立ZIP下载、Windows启动入口、便携说明、完整示例及字段文档。
- 增加打包脚本、包内文件SHA-256清单及ZIP校验文件；页面仍完全离线使用。
- 未改变游戏功能及方块属性。

## 0.1.6 — 2026-10-20

- 新增本地中文内容设计器，14类147项属性，支持功能规则、配方、接口、独立备份字段、兼容适配和验收用例。
- 提供铁质潜艇壳目标预设、浏览器草稿、完整JSON导入导出、扩展需求、JSON Schema及命令行校验。
- 整理采集按铁块、防护/物理/耐压按黑曜石的属性对照表；本次未修改游戏方块属性。
- 数据校验和Schema验证通过；受浏览器工具file协议策略限制，未完成浏览器实机验收。详见[内容设计器](development/内容设计器设计与使用-content-designer.md)。

## 0.1.5 — 2026-10-20

- 新增“铁质潜艇壳”，复制黑曜石方块属性，补齐镐挖掘、钻石级工具、活塞不可推动及末影龙免疫规则；正确工具挖掘掉落自身。
- 使用六面相同的灰色平滑金属贴图，边缘带拼接缝与螺丝，加入“深蓝远航”创造模式物品栏。
- 本次不替换现有潜艇方块，不增加配方或自定义航空学质量、深海学耐压参数。
- 材质与使用说明见[铁质潜艇壳](development/铁质潜艇壳-iron-submarine-hull.md)。

## 0.1.4 — 2026-10-20

- 主世界生成前扫描物品、矿石标签、群系生成配置与挖掘掉落，建立并保存自动矿种池；当前识别 10 种矿石/宝石，排除加工提矿岩石和仅下界生成的矿物。
- 最近三座资源岛依次分配铁、铜、金，其余随机；10000 格以外沿用同等密度和区域规则，按种子随探索生成。
- 保留原有自然矿物，取消旧版支线岛的其他矿石清除与自然装饰拦截。
- 按用户授权重建联合开发存档，保留本机完整压缩回退备份；更新分卷存档交付。
- 详见[自动矿种与无限探索](development/自动矿种与无限探索-v0.1.4.md)。

## 0.1.3 — 2026-10-20

- 修复淹没世界的村庄主体与道路将海面当作地面的问题：村庄按实际地形定位，海面以下的房间填水，可含水的建筑方块设为含水。
- 允许海平面以下原陆地的村庄生成，保留“旧世界被海水淹没”的设定；其他结构沿用既有筛选规则。
- 修复仅作用于深蓝远航淹没世界的村庄生成，不改变普通世界、其他结构的高度查询。
- 按用户要求保留两处已生成村庄及周边建设，不重建旧区块；联合开发存档交付仍为 v0.1.2。
- 验证范围和更新方式见[淹没村庄生成修复](development/淹没村庄生成修复-v0.1.3.md)。
