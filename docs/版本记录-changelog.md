# 版本记录

项目版本同时用于自研 Mod、提交标题与 Git 标签。正式发布目标 1.0 与当前开发版本分别记录。

## 0.1.3 — 2026-10-20

- 修复淹没世界的村庄主体与道路将海面当作地面的问题：村庄按实际地形定位，海面以下的房间填水，可含水的建筑方块设为含水。
- 允许海平面以下原陆地的村庄生成，保留“旧世界被海水淹没”的设定；其他结构沿用既有筛选规则。
- 修复仅作用于深蓝远航淹没世界的村庄生成，不改变普通世界、其他结构的高度查询。
- 按用户要求保留两处已生成村庄及周边建设，不重建旧区块；联合开发存档交付仍为 v0.1.2。
- 验证范围和更新方式见[淹没村庄生成修复](development/淹没村庄生成修复-v0.1.3.md)。

## 0.1.2 — 2026-10-19

- 根据世界种子生成 3 个主线地点，以钻石块核心、海面标记和四向边界标记预留尚未制作的区域。
- 增加 24 座自然起伏支线岛，每岛一条高密度、单矿种矿脉；纳入机械动力锌矿，铁铜金锌矿脉混入对应粗矿块。
- 更新联合开发存档，保留原始岛、船坞缓坡及当前主艇；地图仍限中心 10000 格正方形。
- 新种子从空目录创建地图并完成保存重进验证；交付改为四卷 ZIP 与自动校验导入脚本，清理旧交付和临时存档。
- 布点、矿脉约束和开发默认值详见[随机主线与矿脉支线岛](development/随机主线与矿脉支线岛-v0.1.2.md)。

## 0.1.1 — 2026-10-19

- 船坞地形向周边海床增加 96 格平滑过渡，取消边界处突然切换海床高度的行为。
- 修整当前“深蓝远航·联合开发”存档的水下接缝，保留岛上建筑、船坞作业区和出海通道。
- 后续每次提交递增并标记版本号，保持 Gradle 与 Mod 元数据一致，随提交推送对应 Git 标签。

## 0.1.0 — 开发初版

起始岛、淹没世界、新版潜艇、酒壶控制台与联合开发存档。历史提交未逐次递增版本，最近一次为 b62d24e。
