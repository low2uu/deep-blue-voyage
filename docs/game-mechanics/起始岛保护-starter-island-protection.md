# 起始岛保护

适用于使用 `StarterIslandGenerator` 的主世界。保护范围为 X=-280～280、Z=-216～256，覆盖全高度，包含岛屿建筑和船坞。其他世界、远海及 Sable 的船体内部坐标不受这项保护影响。

## 当前规则

- 普通玩家不能拆除或放置岛上方块，也不能用工具改变方块、倒桶、点火、放置末影水晶或矿车、使用扳手。门、箱子、面板等普通交互保留。
- 创造模式且拥有二级权限的管理员可建设；船坞原有改装权限和事务锁继续生效，管理员不能绕过正在执行的转换。
- 爆炸列表中的岛内方块和实体受到保护；阻止岛内生物破坏事件、耕地踩踏及活塞搬运。活塞边界额外检查13格，防止从外部拉走方块。
- 原版火焰在岛内及边界5格缓冲区停止蔓延，不能烧毁岛内方块；不修改全世界的火焰游戏规则。

这是首版公共岛保护。岛上扩建暂由创造管理员实施，后续再划分玩家可建设地块。活塞保护没有管理员豁免，岛上的原版活塞机械会停止；Create 动力机械仍按自己的机制运行。

## 范围与限制

保护基于 NeoForge 事件和原版火焰逻辑。管理员命令、WorldEdit、直接写入世界的第三方机器，以及模组绕过事件的破坏不属于完整防护认证；不能把它当作面向不可信模组的安全沙箱。未实现区域内所有液体流动冻结，避免破坏港口与机械管路。物理潜艇仍遵循原有可损毁规则。

配置入口：`world/IslandProtection.java` 中 `inBounds`。回归时应检查普通玩家拆方块被拒绝、创造管理员可建设、远海与物理船体不受影响，再检查爆炸与火焰保护。
