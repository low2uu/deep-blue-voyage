# 起始岛无限油田与手动建设

更新于2026-10-15。使用Minecraft 1.21.1、NeoForge 21.1.259、Create 6.0.10和Create: Diesel Generators 1.21.1-1.3.15。根据最新分工，工程负责启用Mod、设置无限原油区和放置边界标识，抽油机、炼油厂、动力与加油设施由玩家建设。

## 位置与生效方式

继续使用当前 `runtime/client/saves/DBV-Island-v3` 存档。更新代码并重新启动客户端后，首次加载主世界的起始岛预设时自动初始化；已有世界不需要重新生成。新建同一预设的世界也会获得该区域。

| 项目 | 范围或行为 |
| --- | --- |
| 无限油田 | **X=176～207，Z=-64～-33**，两端均包含，共32×32格 |
| 区块 | X=11、12；Z=-4、-3，共四个 |
| 建筑位置 | 岛屿工业区东侧原扩建带，不占船坞与生活区 |
| 四角 | 风化铜柱与双面发光文字告示牌；遇已有建筑或树木会跳过，不强拆 |
| 储量 | CDG原生无限储量，产物为原油；不会直接送柴油或创造动力 |
| 区外 | 不改天然油量，不降低全局无限阈值；天然油田仍可能自行满足Mod的无限条件 |
| 性能 | 不使用每tick补油、不铺地下原油方块、不添加强制区块加载票据 |

运行 `/dbv oilfield` 查看范围、四个无限区块及标识数量。需要补设被障碍物阻挡的角标时，清理对应位置后由管理员运行 `/dbv oilfield mark`。已经成功放置后再被玩家拆除的角标不会自动重建。

范围按**抽油井口所在区块**判断，不要求机器整座都放在边界内。建议先把井口设在 `(184,地面以上,-56)`，避开区块边缘。地形保持自然，不会自动整平、建厂或清空玩家方块。

## 玩家建设顺序

1. 在油田内用Mod的原油探测工具确认油量；在JEI中搜索柴油动力物品，长按思索键查看抽油机教程。
2. 建一台完整抽油机，包括支架、主轴承、活动横梁、抽油头、后轴承及曲柄。按思索教程粘合活动结构并装配，给曲柄连接机械动力。
3. 在抽油头下方放井口。井口下面接**连续竖直流体管，一直通到基岩**。当前起始岛陆地下方的底层基岩为Y=-64，管道最低一格为Y=-63；遇到施工改变后的地形，以实际连续管道及原油矿床标签检查为准。
4. 用机械泵从井口侧面抽出原油，送入储罐。先确认原油持续产出，再搭炼油设备。
5. 用蒸馏控制器将足够高的储罐转换为蒸馏塔，提供正常加热，并分别接出柴油、汽油。当前版本普通加热配方每100mB原油产50mB柴油和50mB汽油，基础处理时间60tick；以实际JEI配方为准。
6. 储存柴油并给发动机补给。汽油也需要容器，副产物堵满会影响蒸馏。先采用桶或罐装运输到船坞，移动潜艇自动对接另行测试。

无限的是地下原油储量。抽油动力、流体输送、加热、加工速度、储罐容量和艇载燃料仍按Mod规则运行。当前不提供免费燃料填充器、不自动维持发动机油箱，也不代建启动机械。

## 用地预留

油田核心使用原东侧扩建带的一部分。后续可在剩余用地安排32×32炼油工位、储罐和维修间；现阶段仅有角标，不将这些预算面积全部铺成平台。船坞加油设施应放在岸边，保留中央128×128建造水域与出海口。

## 保存与维护

- `data/cdg_oil_chunks.dat`：CDG原生区块油量。
- `data/dbv_starter_oilfield.dat`：本项目的一次性初始化与标识状态，另保存初始化前的原生油量表快照。
- 初始化只在主世界且生成器为本项目起始岛预设时执行；其他预设、下界、末地和深海维度不修改。
- 重启不重新设置油量、不重建角标、不恢复拆掉的设施。更改全局无限阈值可能影响CDG解释现有储量，当前保持默认配置。
- 回退前备份整个世界；不要单独删除初始化记录来反复覆盖油量。本次运行前的v2完整备份位于 `runtime/backups/DBV-Island-v2-before-oil-20261015-104940`。
