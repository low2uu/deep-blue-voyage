## 机器空间与船坞边界

实际工位坐标经过建筑墙体避让，范围均为左闭右开；本表替代早期方案中的室内摆放草案。地坪为Y=68，第一格可用空间为Y=69。

| 通用工作站 | 82～106 | -62～-38 | 16格 |
| 刷铁 | 108～124 | -62～-46 | 12格 |
| 安山合金 | 108～124 | -42～-26 | 12格 |
| 动力 | 86～98 | -106～-94 | 12格 |

船坞中央范围为X=0～128、Z=112～240；两侧栈桥位于中央范围以外，入口在Z≥240方向。Y=13～62至少保留50格深的水域，中央上方没有横跨船坞的梁或屋顶。未来潜艇的运动碰撞、旋转半径和下水方式仍需按实体原型验收；这里保证的是建筑空间，不宣称已经验证船舶物理。

出生点位于小屋旁广场 `(-84,69,-28)`。庭院和建筑陈设只使用原版方块，没有植入Create生产线、船体、NPC或任务。

## 进入和共同开发

在项目根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\dev.ps1 run
```

进入单人游戏，选择 **Deep Blue Voyage - Harbor Island v1**。自动取景和验收脚本已移出客户端，不会在下次进入时传送玩家或自动退出。

建筑与自然景观生成代码在 `mods/dbv-world/src/main/java/io/github/low2uu/dbv/world/IslandArchitecture.java`，地形规则在 `IslandTerrain.java`。后续新建该预设的世界可以复现初版；既有区块不会被代码自动重新刷写。因此修改生成代码之后，不要期待已建成存档中的建筑自动更新，也不要删除已施工区块来强行更新。后续局部改建直接在此存档或经过备份的结构部署中完成。

已验收的地图快照随仓库保存在 [DBV-Island-v1.zip](../../assets/worlds/DBV-Island-v1.zip)。合作者首次运行工程后，关闭游戏，将压缩包中的 `DBV-Island-v1` 文件夹解压至 `runtime/client/saves/`，再启动客户端进入该世界；已有同名存档时先备份，不要直接覆盖。使用时保持当前工程与Mod版本一致，不要将自定义生成器存档直接交给缺少dbv-world的纯原版环境。日常运行存档和备份仍在Git忽略目录，仓库中的压缩包是本次建设完成的固定快照。
