# 深蓝远航1.0游戏机制说明

更新日期：2026-10-20。目标平台：Minecraft 1.21.1 NeoForge。

**1.0指首个公开版本。本文仅收录目前已经确认的1.0规则和基础参数；确认设计不等于已经实现。** 后续新增内容须经用户确认，不能因为出现在旧方案、已安装Mod或开发原型中，就自动算入1.0。

## 海洋与潜艇冒险

以海洋为主导，围绕建造潜艇、海底航行与冒险展开。地图需要为大型潜艇保留足够的航行和建设空间，同时通过不同地区的考验，让推进能力、船体耐压和艇体大小各有作用。

初始小岛作为开局基地，也是主线范围的参考中心。

### 海面上升后的世界

地图以正常世界的自然地形为基础，保留山地、谷地和平原等地貌，再将海面提升到Y=128，使低地成为海底，高地形成陆地与岛屿。结合Mod相关地形内容，最终补充适合海洋环境的生态、动植物。不能用统一平底海床代替这一大环境；各Mod在技术上的生成阶段可以协调，但最终地形与生态应符合海面上升后的环境。

初始开发存档也采用该方向。2026-10-20 已取消临时的10000格探索与生成边界，范围外沿用相同区域和资源岛规则，按世界种子随探索生成；范围外没有主线任务。旧边界方案作为历史保留。当前实现见[自动矿种与无限探索](../development/自动矿种与无限探索-v0.1.4.md)。

## 地图范围与随机分布

| 项目 | 已确认规则 |
| --- | --- |
| 主线区域 | 3个，分别考验速度、抗压和小体积通行 |
| 主线范围 | 以初始小岛为中心，总边长10000格的正方形；向四边各延伸5000格 |
| 区域位置 | 在地图上随机生成，不采用固定地点布置三个主线区域 |
| 范围之外 | 仍生成这三类区域，但不包含主线内容；10000格正方形不是世界边界 |
| 支线小岛 | 3种类型，随机分布；不是全世界仅有3座岛 |

“随机刷新”目前只确认随机分布，不据此确定定时重建或覆盖已生成岛屿。三种支线类型的具体内容、数量和间距尚未确认，因此不写入1.0规则。

## 资源岛矿物（2026-10-20 确认）

生成前自动筛选明确在主世界自然生成、可以挖掘获得的矿石和宝石；绯红岩等加工提矿岩石不纳入。保留原有自然矿物生成。距离初始岛最近的三座资源岛分别保障铁、铜、金，其他岛屿随机；10000格以外同样适用资源岛生成规则。具体扫描兼容范围、每分区数量与间距属于开发实现参数。

## 三个主线考验

| 区域主题 | 已确认的核心机制 | 后续需要确定的参数 |
| --- | --- | --- |
| 速度考验区域 | 通过洋流速度形成通行考验，要求潜艇具备相应推进与航行能力 | 流向、流速、所需航速及具体航段 |
| 深海区域 | 通过深度压力考验潜艇抗压能力；船体材料的坚硬程度参与耐压设计 | 材料分级、允许深度、压力和损伤规则 |
| 冰川区域 | 通过狭小空间形成体积限制，需要小体积潜艇进入 | 艇体尺寸、通道净空及通行判定 |

三个主题已经确定；名称、推进顺序、任务、Boss、奖励和配方均不在本次确认范围内。这里不将三个考验排列成必须依次完成的科技路线。

## 初期航速与航行时间

| 项目 | 已确认目标 |
| --- | --- |
| 初期最高航速设计基准 | 4格/秒 |
| 初期满速到目的地 | 约10分钟 |
| 初期满速到主线范围边界 | 约20～30分钟 |

这些是设计目标，**当前原型尚未实现4格/秒的目标航速**。地图密度按这一目标继续设计，不再以当前Mod默认推进表现决定地图规模。

时间按纯航行理解，探索、停靠和战斗另计。“10分钟到目的地”暂用于首程规划，不将其扩展成三个主线区域都必须位于同一距离。作为换算参考，4格/秒航行10分钟约2400格；从中心直达四边中点约20分50秒，直达四角约29分28秒。换算结果不等于已经确定随机布点半径或路线。

## 安全航行层与世界高度

设置一个通常不增加地区限制、可安全自由航行的深度层，再分别设计各地区的深度。**安全层的具体上下界尚未确认。** 它不是整个世界取消压力、洋流或体积考验；三个主线区域仍分别承担上述考验。

| 高度参数 | 当前基准 |
| --- | --- |
| 海面 | Y=128，水面最上层水方块位于Y=127 |
| 世界最低高度 | Y=-256 |
| 最高可放置方块 | 保持Y=319 |
| 世界总高度 | 576格 |

以海面为基准，深度可按`128－世界Y`换算。高度调整及旧岛整体上移65格已经完成；旧岛保留区保持原相对水深，外海已改为自然地形被淹没后的海洋，不能据此认为深海主线已经建成。
