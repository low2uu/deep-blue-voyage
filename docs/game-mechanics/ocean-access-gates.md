# 海域准入与潜艇能力限制

不同海域通过环境条件对潜艇提出要求。玩家通过改装、换艇、规划路线和携带设备进入新区域，形成探索与造船之间的成长循环。

首要方向是洋流速度锁、深度压力锁和通行尺寸锁。续航作为配套设计优先验证；其他限制保留为后续候选。以下为玩法设计，具体参数和物理实现尚未锁定。

## 限制类型总览

| 机制 | 环境要求 | 突破方式 | 适用内容 |
| --- | --- | --- | --- |
| 洋流速度锁 | 逆流需要足够航速，横流要求姿态与方向控制 | 升级推进、减阻、减载、侧路或缓流窗口 | 海峡、洋流通道、深海喷流 |
| 深度压力锁 | 随深度增加的水压超过船体承受能力 | 耐压材料、结构加强、缩小舱跨度、维修 | 深海盆地、海沟、深渊 |
| 通行尺寸锁 | 入口、裂隙、通道和急弯限制船体通过 | 小艇、子艇、收起或拆除外设、离艇潜水 | 洞穴、沉船内部、封闭遗迹 |
| 续航锁 | 远距离目标且缺乏沿途补给 | 储能、效率、中继基地、补给艇 | 无岛大洋、远征区域 |
| 探测锁 | 黑暗、浑浊和复杂地形妨碍寻找目标 | 测深、声呐、信标、地图和坐标线索 | 深渊遗迹、隐藏裂隙 |
| 环境防护锁 | 高温或腐蚀持续影响设备和船壳 | 隔热、防腐、冷却与防护层 | 热液喷口、火山海域、特殊盐水层 |
| 机动性锁 | 急弯、竖井、暗礁要求精确操控 | 侧推、姿态控制、重心和船型调整 | 曲折海沟、洞穴群 |
| 噪声锁 | 生物对发动机、声呐和作业噪声敏感 | 静音航行、关闭设备、绕行和诱饵 | 巨兽巢区、潜行探索 |
| 作业能力锁 | 到达后仍需切割、钻探、牵引或回收 | 工具、机械臂、工程子艇、潜水装备 | 打捞、特殊矿床、遗迹开门 |

## 洋流速度锁

洋流具有方向和流速。潜艇的相对水体航速与海流共同决定相对海床的运动。沿同一直线逆流时，可用以下简化关系解释给玩家：

**实际前进速度 = 潜艇相对水体的逆流航速 − 洋流速度。**

结果小于或等于零时，潜艇不能继续逆流推进。横流还会造成偏航，需要调整航向或使用侧推。实际游戏采用何种推力、阻力和海流计算，在原型中确定。

突破途径应包括推进升级、降低船体阻力、减少负载和选择其他航线。减载对航速的作用需要通过游戏模型验证，不能直接把质量等同于水中阻力。

### 预警与返航

顺流进入不代表能够逆流返回。入口和仪表应提供流向、流速、预计逆流能力和返航风险提示。危险通道附近可布置避流区、停泊点或另一条出口。

动态洋流、缓流窗口和潮汐属于扩展设计。第一轮可以使用可预测的固定流场，先验证驾驶和返航规则。

洋流也应提供收益：顺流节能、加快远航、形成贸易航线，让路线知识成为成长的一部分。

## 深度压力锁

水压随深度增加。船体超过建议潜深后，应依次通过异响、警报、渗漏和局部破损反馈风险，给玩家上浮、隔舱和维修的时间。具体损伤速度与极限深度待平衡。

### 材料属性

| 属性 | 作用与取舍 |
| --- | --- |
| 硬度与抗冲击 | 抵御撞礁、碎石和攻击，不直接等于耐压 |
| 耐压能力 | 决定材料用于耐压结构时的承受能力 |
| 密度 | 改变船体质量、浮力需求和操控负担 |
| 耐腐蚀与耐热 | 影响特殊环境中的耐久 |
| 维修难度 | 决定物资消耗、维修速度和现场可修复性 |

材料可以形成坚硬但沉重、轻便但耐压不足、耐压优秀但维修昂贵等不同选择。结构加强和更小的耐压舱跨度是候选设计，具体收益需保证玩家容易理解。

### 耐压判定与弱点

判定应关注真正围成舱室的船壳，并考虑玻璃、舱门、接口和已有损伤。不能通过在舱内放置一块高级金属提升整艇耐压，也不能简单用所有方块的平均等级掩盖薄弱船壳。

需要在原型中确定按舱室还是按整艇计算耐压，以及双层船壳、外部装饰、连接口和局部破损如何处理。未确定前不提供虚假的精确公式。

装配检查与驾驶仪表应显示建议最大潜深、薄弱舱段、当前风险、升级建议和损伤后的安全余量。发生泄漏时允许隔离局部舱室，争取撤离时间。

## 通行尺寸锁

体积锁按实际通行尺寸设计，而非只比较总方块数或总体积。细长艇可能通过窄洞，体积更小但更宽的艇反而无法通过。

通行条件包含宽度、高度、长度、朝向和转弯空间。炮塔、机械臂及其他突出部件要计入；可收起部件应按实际状态计算。复杂洞穴既要检查入口，也要检查内部转弯和返程空间。

### 母艇与子艇

**大型母艇负责远洋运输与生活 → 小型子艇进入洞穴 → 玩家潜水进入遗迹内部。**

母艇提供子艇停泊、充能、维修和货物转运。小艇保留进入狭窄区域的独特价值，不会在大艇建成后失去用途。

入口附近应有适合母艇停泊和人员转运的位置。玩家应能通过测绘、扫描或清晰地形观察判断通行条件。卡住后应有倒退、牵引、拆除外设等恢复手段，避免只能弃船。

## 扩展限制的设计边界

续航限制需要展示可用能源、预计消耗和返航储备，并允许用前哨基地扩展航程。探测限制应提供可发现的线索，避免只能盲搜。

噪声限制应有可理解的声源和敌人反馈，允许主动声呐与静默航行之间的取舍。环境防护应提前呈现危险征兆。作业能力限制应允许玩家先发现目标、标记位置，再携带设备返回。

这些扩展先作为区域内容候选，不同时强加给所有海域。

## 区域组合示例

| 区域 | 主要限制 | 探索方式 |
| --- | --- | --- |
| 急流海峡 | 速度与操控 | 强推进艇逆流突破，或寻找缓流窗口 |
| 深渊海盆 | 耐压与续航 | 耐压母艇远征，建立补给前哨 |
| 海底裂隙 | 尺寸与耐压 | 母艇停入口，小型耐压子艇进入 |
| 巨兽巢区 | 噪声与探测 | 低速静音，谨慎使用主动声呐 |
| 热液遗迹 | 防护与作业能力 | 工程艇携带防护和切割设备 |
| 沉没设施 | 尺寸与潜水能力 | 子艇接近，人员离艇进入 |

## 成长与验证顺序

第一轮验证速度、压力、尺寸与续航。早期区域突出一种限制，后期组合两到三种，并尽量保留绕行、换艇或建立前哨等不同解法。

| 验证项 | 通过标准 |
| --- | --- |
| 风险可读性 | 玩家进入前能判断主要危险，进入后能看懂设备反馈 |
| 洋流 | 不同流向影响正确；临界航速有清晰表现；返航有可判断条件 |
| 耐压 | 更换薄弱船壳产生可解释变化；舱内高级方块不能作弊提升耐压 |
| 尺寸 | 比较不同长宽高的艇，确认不是只按方块总数判断；入口及返程均测试 |
| 故障恢复 | 超深、漏水、卡艇和能源不足有预警及可操作的救援路径 |
| 成长闭环 | 升级材料可以在当前能力范围内获得，不出现解锁死循环 |
| 小艇价值 | 大艇建成后仍有适合子艇与离艇探索的内容 |
| 多人与性能 | 海流、舱室状态、载具位置和损伤同步稳定，满足目标服务器负载 |

下一轮需要确定潜艇原型尺寸、流速区间、海域深度层、材料耐压等级、预警到破损的时间、基础续航和子艇停泊方式。
