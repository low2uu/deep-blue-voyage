## 2. 整体循环与推进路线（待定）

核心循环：**获取线索 → 出海调查 → 带回样本 → 岸上加工 → 船坞改装 → 挑战区域核心 → 解锁专精设备。**

三个地区可以分别推进，不强制按固定顺序完成。

| 路线 | 玩家主要解决的问题 | 主要升级收益 |
| --- | --- | --- |
| 急流海域 | 推进不足、逆流航行、移动目标战斗 | 推进、操控、远航效率 |
| 深海盆地 | 船壳耐压、设备保护、破损维修 | 深潜、损管、重型作业 |
| 冰川迷宫 | 船体过大、狭窄路线、离艇操作 | 小艇、探测、精确作业 |

待定节奏目标：

- 前30分钟：熟悉初始艇、储存、停泊、供氧和一次浅水打捞。
- 约2～4小时：完成第一条地区路线的入门改装与首次核心挑战。
- 首次完成三条路线：约12～20小时，建造时间另计。
- 三条路线完成后：开放“联合远征”，综合运用三种能力，先复用现有地区，不急于增加第四个地区。

## 3. 海域分层与特色（设计与数值待定）

潜艇仪表深度以中央控制器的世界位置为基准：`D = 当地海面高度 − 控制器世界Y`。本世界海面基准为128。下表地区深度表示内容布点范围，不能直接当作整艇最深位置；艇底、艇顶与外设还需单独检查净空和材料适用性。

| 地区草名 | 建议深度 | 环境特色 | 主要产出 |
| --- | --- | --- | --- |
| 初始岛与港湾 | 0～50格 | 温馨生活区、废旧工厂、船坞、维修与教学残骸 | 基础工业材料、食物、入门补给 |
| 公共航行层 | 0～60格 | 连通航路、浮标、远方地标；无主动追猎Boss | 航行线索、少量漂流物 |
| 普通海底 | 60～120格 | 淹没山谷、海草林、沉船、村落残骸 | 自然矿物、废旧零件、基础生物材料 |
| 急流·回旋海峡 | 核心80～120格 | 流道、避流湾、撞毁运输船、周期性流向提示 | 柔性纤维、导流材料、推进零件 |
| 深海·沉钟盆地 | 盆缘100～140格；核心200～260格 | 阶梯盆地、黑暗残骸、发光生物、废弃观测站 | 耐压与密封材料、精密回收件 |
| 冰川·白幕迷宫 | 核心80～120格 | 冰下洞道、宽母艇泊位、小艇转弯室、人员通道 | 轻量材料、声学晶体、精密控制件 |

安全层不等于无敌：碰撞、燃料耗尽、开舱进水仍有效。强流与区域战斗集中在主动进入的深层核心。冰川首版不再叠加强制低温升级，避免同时要求耐压、抗寒、小体积三套门槛。

- 生物材料提供便捷路线，但核心工业不能完全依赖刷怪。

## 6. 潜艇升级目标（除初期4格/秒外，数值待定）

推进、耐压、后勤与火控分别升级，不采用升级一次就全属性增加的船只等级体系。

| 系统 | 初始配置目标 | 一级改装目标 | 二级专精目标 |
| --- | ---: | ---: | ---: |
| 满载静水持续最高航速 | 4格/秒，已确认目标但非已达成 | 5.5格/秒，待定 | 7格/秒，待定 |
| 配套船壳工作耐压 | 140格级 | 220格级 | 300格级 |
| 建议任务控制器深度上限 | 120格 | 190格 | 260格 |
| 常规巡航续航 | 45分钟 | 65分钟 | 90分钟 |
| 主供氧失效后的应急氧气 | 2人5分钟 | 2人8分钟 | 2人12分钟 |
| 有效声呐识别距离 | 96格 | 160格 | 224格 |
| 建议战斗配置 | 轻炮或手动武器 | 轻炮＋鱼雷 | 两种武器＋专用辅助设备 |

验收口径与待定边界：

- 表内为整艇目标，不直接修改航空学速度常量或凭空增加升力。质量、阻力、推进和浮力仍由原模组计算，通过设备与船型达到目标；是否需要额外兼容开发待核对。
- 船壳耐压需匹配玻璃、门、接口和特殊方块；不只换外壳。建议任务深度与材料等级之间留余量，不承诺仅靠余量就能覆盖任意大型艇。
- 常规对比工况建议取设计载荷80%，另做100%满载返航验收。表中满载速度须在100%设计载荷下核对；设计载荷、燃料与弹药基准、TPS及测试距离仍待确定，不能混用工况。
- 初期往返纯航行约20分钟，初始45分钟续航用于同时容纳作业与返航储备。巡航续航不等于同时开炮、生产和制氧时的综合续航；燃料消耗与容量需实测后反推，不虚构FE换算。
- 应急氧气按两人参考负载规划，具体供氧机制、舱室体积及其他乘员人数的消耗尚待验证。
- 声呐不默认加载未生成区块，也不直接揭示所有宝箱。

### 洋流门槛（待定）

| 流道 | 逆向流速 | 预期体验 |
| --- | ---: | --- |
| 教学流道 | 1格/秒 | 初始艇约3格/秒地速 |

### 冰川小艇（待定）

- 推荐长15、宽7、高7格，包含外设。
- 核心通道净宽、净高各11格；主要转弯室至少32×32格平面空间，仍需实际驾驶验收。
- 主艇停外侧，小艇为附属载具，不占用唯一主潜艇身份；与主艇识别、设备登记的具体关系另行实现。
- 提供可借用基础小艇或低成本蓝图，避免探索主线突然变成数小时造船。
- 冰体保护、可挖掘路线、绕行与核心完成条件尚未确定，不据此将全区冰块设为不可破坏。

## 7. 战斗口径与设备损伤（全部待定）

玩家生命以Minecraft标准20点＝10颗心作为初始平衡基线；敌人生命也以生命点计。难度与装备基准需在实现前固定。

船体不简单套总血条：船壳破损、进水、供氧和设备失效共同决定生存能力。下表“设备耐久”是拟新增的战斗损伤层，不等同方块硬度、爆炸抗性或Deep Seas耐压，也不表示当前Mod已经实现。

| 项目 | 初始建议值 |
| --- | ---: |
| 普通外部设备战斗耐久 | 100 |
| 加装护罩的设备耐久 | 160 |
| 重型受保护设备耐久 | 240 |
| 低耐久报警 | 低于30% |
| 单个维修包恢复耐久 | 40 |
| 现场维修时间 | 6秒，受击中断 |
| 普通敌人攻击玩家 | 当期标准装备下单次实际扣血2～4 |
| 精英攻击玩家 | 实际扣血4～6 |
| Boss普通攻击玩家 | 实际扣血4～6 |
| Boss重击玩家 | 实际扣血8～10，至少2秒明确预警 |
| 普通敌人攻击设备 | 每次8～15耐久 |
| Boss攻击设备 | 普通18～25，重击35～45耐久 |

对玩家伤害是穿戴当期装备后的验收值，实现时反推原始伤害，不能重复减伤。攻击频率、护甲公式、命中判定、无敌帧、附着伤害周期和设备失效效果尚未定，不能仅凭这张表认定生存时间平衡。

避免无预警秒杀，危险来自连续失误、进水与设备故障的叠加。压力造成的原生损伤与战斗耐久如何衔接、是否会重复结算，需先做兼容验证。

## 9. 三个Boss与奖励（全部待定）

平衡基准为1名玩家＋酒狐辅助。酒狐使用船上真实武器，不凭空额外增加伤害；目标有效DPS为参考整套配置在有效交战时间内的总输出，不是每名玩家或每门炮各自的目标。

| Boss草名 | 核心玩法 | 基准生命 | 目标有效DPS | 预计完整战斗 |

多人生命提案：`Boss生命＝基准生命×[1＋0.6×（参与人数−1）]`。2人为1.6倍，4人为2.8倍；直接伤害不随人数增加。人数开战时锁定，掉线不立即降生命，酒狐不计人数。中途加入、多人多艇与多人接管火控的输出增长仍需专门测试。

## 11. 酒狐、主艇档案与恢复（规则提案待定）

酒狐首版建议承担：

1. 出航检查：报告耐压、燃料、氧气、弹药和返航储备。
2. 驾驶辅助：已测路线巡航、定点值守、接应；未知障碍停下提示。
3. 战斗辅助：玩家授权后操作一个实际武器岗位，优先清附着怪，再处理威胁。
4. 损管提醒：指出出问题的舱室/设备与可采取的操作。

AI自动战斗保留至少25%弹药用于撤离，不擅自开启未授权Boss战。玩家可接管同一岗位，不能玩家和AI对同一武器重复结算。弹药保留按何种弹种与库存基准计算、紧急覆盖权限及AI失联行为仍待确定。

沿用船体建设、实际容器、设备状态统一独立存储的方向，进一步区分三类操作：

| 档案用途 | 提案规则 |
| --- | --- |
| 改装备份 | 用于取消本次改装，不能当作重置任意远航消耗的存档 |
| 航行恢复档案 | 跟随真实消耗、建造、容器与设备状态更新 |
| 损毁重部署 | 同一主艇身份只有一个有效实例，不能同时恢复全套船货又保留可重复打捞的完整旧艇 |

快照一致性、恢复成本、失事货物处理、恢复时旧载体失效和异常回滚事务仍需设计。此处为防复制的目标，不宣称已有完整灾难恢复；不能靠反复恢复复制弹药、货物或装备。

## 12. 首轮制作范围建议（待定，非开发授权）

先验证一条完整体验链：**初始岛出发 → 普通残骸教学 → 急流外围采样 → 一级推进改装 → 核心流道 → 回旋巨鳐 → 带回奖励。**

建议第一批：

- 普通海底3种怪、急流3种怪、1个Boss。
- 基础密封件、增强纤维束、导流组件。
- 轻炮、鱼雷、维修包。
- 初始4格/秒与升级5.5格/秒两档整艇目标。
- 酒狐值守、基础火控、损管提醒。
- 完整出航、战斗、返航、补给与恢复流程。

先验证每次远征收益、维修负担与升级收益，再铺开深海和冰川；后两者按共享材料与数值口径预留，不另做互不相通的成长体系。
