# 艇载 AI 与玩家协同战斗

艇载 AI 为潜艇提供辅助驾驶、航行托管和自动战斗能力。玩家离艇探索或与 Boss 交战时，潜艇仍可保持位置、提供火力、照明与接应，成为能够共同作战的伙伴。

当前为功能设计，尚未实现。先验证稳定驾驶、目标识别和玩家接管，再扩展战术协同；不要求通过联网对话模型控制潜艇。

## 控制模式

驾驶与武器分别设置控制权，允许玩家驾驶、AI 操作武器，也允许 AI 驾驶、玩家瞄准开火。

| 模式 | AI 行为 | 玩家操作 |
| --- | --- | --- |
| 辅助驾驶 | 定深、定向、姿态稳定、障碍与状态提醒 | 保持驾驶，随时调整目标 |
| 航行托管 | 沿指定航点行驶，控制速度并避障 | 指定目的地、航线和返航条件 |
| 原地值守 | 在安全范围内悬停，监视周边与船况 | 离艇探索或处理船内事务 |
| 跟随与接应 | 在指定距离外跟随玩家或子艇，驶向可达的接应点 | 设置跟随距离，发出接应指令 |
| 防御托管 | 攻击进入防御范围的有效敌人，保护玩家与潜艇 | 设置保护对象、禁射区和交战范围 |
| 区域清剿 | 在指定区域巡航并自动攻击普通敌人 | 指定区域、目标类别、弹药预算和结束条件 |
| Boss 协同 | 根据标记和战斗阶段提供火力、牵制、拦截与接应 | 主导战术、处理关键机制并下达指令 |

手动接管应立即停止对应系统的 AI 指令。多人时分别指定驾驶、火控和指挥权限，同一系统同时只接受一个控制来源。界面持续显示当前模式、控制者和正在执行的命令。

## 辅助驾驶与航行托管

AI 使用潜艇已有的传感器、动力和控制设备，不提供无限探测、额外推力或耐压加成。路线必须满足[海域准入条件](ocean-access-gates.md)：逆流能力、耐压深度、实际通行尺寸和返航能源。

规划要考虑整艘艇的尺寸、转弯空间、制动距离及突出设备，不能只判断船体中心点是否能够通过。未测绘区域采用低速探测；看不清、无法通过或无法确认安全时，应停在可维持的位置并请求接管。

跟随玩家时保留安全距离。玩家进入狭窄洞穴后，母艇停留在入口附近的安全点，由子艇或人员继续探索，避免母艇强行跟入。

玩家可以配置低能源、低氧、严重漏水和超深时的应急策略。返航、上浮或靠近玩家都需要可行路径；洞顶封闭时不能盲目上浮。路径不可达时报告原因并执行当前可行的保命动作。

## 自动打怪与火控

自动战斗分为防御和区域清剿。防御优先处理正在威胁玩家或船体的敌人；清剿允许潜艇在指定区域主动寻找普通敌人，但不无限追击到未知海域。

| 火控能力 | 规则 |
| --- | --- |
| 目标识别 | 区分敌对生物、普通海洋动物、玩家、友方载具与中立对象；不能确认时不自主开火 |
| 玩家标记 | 玩家可指定集火、忽略或优先保护的目标 |
| 武器选择 | 根据距离、射界、弹药和目标特征选择可用武器 |
| 射击检查 | 检查本艇、友军、地形遮挡、弹道和爆炸波及范围 |
| 资源管理 | 消耗真实弹药与能源，遵守装填、冷却和过热限制 |
| 追击约束 | 不越出指定活动范围，不突破耐压、航速和续航边界 |
| 停火条件 | 目标失效、友军进入危险区、资源低于保留量或收到停火命令 |
| 战后处理 | 停止攻击、报告消耗与损伤；打捞仍需要对应设备和可达路径 |

玩家游到敌人与炮口之间时，AI 应暂停对应武器或换用安全射界。爆炸武器需要考虑水下爆炸对人员、艇壳和遗迹的影响，不能仅检查瞄准线。

托管可以自动完成普通遭遇战，Boss 则保留玩家参与的关键环节。不能只靠提高 Boss 血量来抵消潜艇火力，而应通过站位、部位、阶段与任务分工设计协同价值。

## 玩家与潜艇共同挑战 Boss

潜艇承担持续火力、牵制、拦截小怪、探测照明和应急接应；玩家负责灵活走位、标记弱点、开启装置、近距离破坏或进入狭小空间。单人可以让 AI 补足船员职责，多人可以手动接管相同岗位。

| 战斗情境 | 潜艇职责 | 玩家职责 |
| --- | --- | --- |
| 重甲巨兽 | 牵制并用重武器压制可攻击部位 | 绕侧破坏薄弱组织，制造破甲窗口 |
| 遗迹守卫 | 清理外围敌人，保护撤退与补给区域 | 进入遗迹关闭防护装置，暴露核心 |
| 快速海怪 | 跟踪目标，保持合适距离并拦截小怪 | 标记攻击窗口，诱导敌人进入有利位置 |
| 巢穴战 | 母艇守住外部通道并提供补给 | 使用子艇或潜水进入巢穴完成目标 |
| 撤离阶段 | 压制追击者，驶向安全接应点 | 脱离战斗、返回潜艇并参与损管 |

上述为 Boss 原型方向，不要求每场战斗都重复同一流程。部分 Boss 适合船上作战，部分需要离艇，也可以在阶段之间切换。

### 协同指令

优先提供少量明确指令：集火标记目标、保护我、保持位置、保持距离、清理小怪、停止射击、前来接应、撤退。玩家应能通过快捷操作下令，无需在战斗中逐项调整复杂菜单。

AI 反馈目标、执行状态、无法执行的原因和重要资源告警。例如“友军进入爆炸范围，暂停射击”或“接应点过窄，已停靠洞口”。避免持续播报无关状态。

### Boss 对潜艇的反制

Boss 应能够对潜艇产生实际威胁，例如冲撞、攻击外部设备、迫使转向或召唤小怪干扰。攻击需要可辨识的前兆和躲避、拦截或维修机会。

必须验证 Boss 寻路、仇恨、命中箱、投射物和运动船体损伤。若某类敌人无法识别或攻击潜艇，不能把其直接视为完成的舰艇 Boss 战。

## 成长与设备配置

| 阶段 | 能力 | 对潜艇的要求 |
| --- | --- | --- |
| 基础辅助 | 定深、定向、状态报警 | 基础控制与传感器 |
| 航行托管 | 航点巡航、值守、返航辅助 | 测深与障碍探测、可靠控制设备 |
| 防御托管 | 目标识别、炮塔控制、小怪拦截 | 火控、武器、弹药补给与稳定供电 |
| 战术协同 | 玩家标记、跟随接应、Boss 阶段配合 | 更完整的探测、通信与船载设备 |

升级扩展可执行任务与协同方式，不凭空增加船体属性。设备占用空间、能源和材料，使侦察艇、战斗艇与综合母艇有不同配置取舍。设备受损后对应能力降级，并向玩家明确反馈。

## 故障与运行边界

- 能源不足时保留生命保障、必要操控与返航储备，按配置减少非必要战斗。
- 传感器失效时停止依赖该信息的自动任务，保留可靠的基础辅助。
- 玩家失联、死亡或离线后的行为需要可配置，默认停止主动追击并进入安全值守；不在无人在线时持续刷怪获利。
- 自动航行遇到未加载区域时应限速或暂停；需要远程持续运行的功能另行验证区块加载、服务器成本和存档行为。
- 存档重载后先复核位置、目标、控制权限和航线，不立即恢复未确认的开火动作。

## 实施与验证顺序

先完成定深、定向、值守和手动接管；再完成安全水域航点巡航与接应；随后验证单种武器的目标识别和自动防御；最后制作一个玩家与潜艇分工明确的 Boss 原型。

| 验证项 | 通过标准 |
| --- | --- |
| 接管 | 玩家接管后 AI 不争夺控制，多人命令不会互相覆盖 |
| 航行限制 | 不超深、不强行进入窄道，逆流与返航储备判断可解释 |
| 安全射击 | 对友军遮挡、本艇遮挡和爆炸范围做出正确停火响应 |
| 普通战斗 | 能在限定区域自动完成遭遇战，资源消耗正确且不无限追击 |
| Boss 协同 | 潜艇有明确贡献，玩家有主动操作；单人与多人均能完成 |
| 故障恢复 | 低电、漏水、探测失效、失联和重载后行为符合设定 |
| 性能 | 路径规划、目标扫描、船体物理和多人同步共同运行时保持可接受负载 |

待原型确定：指令范围、探测刷新频率、跟随距离、交战半径、弹药保留量、撤退阈值、武器类型和各阶段解锁成本。
