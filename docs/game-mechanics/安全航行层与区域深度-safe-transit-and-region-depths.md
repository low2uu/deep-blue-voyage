# 安全航行层与区域深度

日期：2026-10-16。适用：首个公开版本地图设计，Minecraft 1.21.1 / NeoForge。

用户要求设置通常不加限制、可安全自由航行的深度，再分别设计各地区深度。下列具体深度和配套数值为初版提案，尚未写入生成器、压力规则或正式存档；继续暂停运行测试。

## 全海域共用的安全航行层

建议将**水深0～60格**作为安全航行层，常用巡航控制器深度为**20～35格**。所有深度均相对当地海面向下计算，海面为D=0，不直接用世界Y坐标表达难度。

这层主要承担赶路、自由探索、绕行、补给和返航：

- 不设置主线级速度锁、压力锁或小体积通行锁；初期艇可按已确认的4格/秒持续最高航速进行航程规划。
- 推荐航路默认无流；非主航路可有微弱环境流，但不能形成必须升级才能通过的阻挡。强洋流和下吸流留在更深处。
- 不安排强制战斗或Boss主动巡猎；深处Boss原则上不追入公共航行层，以保证明确的撤离方向。具体战斗脱离规则另行设计。
- 保留正常海水、燃料、氧气和碰撞规则。“安全”指不增加区域准入门槛，不代表搁浅、撞山、开舱进水或燃料耗尽也没有后果。
- 安全航路相互连通，绕开岛屿、礁石和冰山。不是将整个水平面挖空：陆地不能穿过，但自然障碍旁必须有无需升级的宽阔绕行路线。

### 大型潜艇净空

控制器深度不代表艇顶和艇底深度。设控制器深度为D，艇体向上延伸U格、向下延伸B格，建议巡航满足：`D - U ≥ 5`、`D + B ≤ 55`，上下各留5格余量。20～35格只是常用驾驶参考，不能保证任意尺寸的艇都适用。

建议公共主航道按**至少128格宽、至少50格连续水下净高**预留，局部转弯和停泊区进一步放宽，保持自然海床轮廓，避免挖成等宽直线水渠。这些净空是首版设计目标，仍需结合后续确认的母艇最大尺寸确定，不构成无限大潜艇通行承诺。

## 深度分层

| 深度D | 定位 | 设计规则 |
| --- | --- | --- |
| 0～60格 | 安全航行层 | 自由往返，不布置主线准入锁 |
| 60～80格 | 预警与过渡层 | 逐渐变化的地形、光线和环境提示；进入明显危险前提供回头空间 |
| 80～140格 | 专项探索层 | 速度区与冰川核心的主要范围，分别考验速度和尺寸；普通海域不因达到此深度自动出现关卡 |
| 140～200格 | 深海进阶层 | 压力考验逐步加强，安排分段目标与安全撤离路线 |
| 200～260格 | 首版深海核心层 | 高耐压主线作业、遗迹与Boss区域；首版暂不依赖更深水域 |

60格是地图安全层的边界，不是潜艇瞬间开始受压损坏的统一阈值。实际损伤由船体耐压能力决定，并提前预警；某一地区的门槛不能直接扩散到同深度的整个世界。

## 各地区深度设定

| 地区 | 海床/任务的建议深度 | 主艇停泊与进入方式 | 主要考验 |
| --- | --- | --- | --- |
| 初始岛近岸 | 港湾局部20～50格；向外过渡到60～100格 | 港湾和船坞以实际吃水与建筑尺寸设计，出港接入安全航路 | 熟悉驾驶，不设置主线锁 |
| 普通外海 | 海床一般80～120格，起伏自然，偶有更深海盆 | 0～60格保持连通航路；下方可布置普通探索点 | 自由航行、打捞和资源探索 |
| 速度主线：急流海域 | 外围海床80～120格；核心流道与任务约80～120格 | 母艇先在20～40格深的避流水域停靠，再进入深层流道 | 强流集中在核心通道；上方安全层不受强流阻挡 |
| 抗压主线：深海区域 | 盆缘100～140格；进阶目标140～200格；核心200～260格 | 上层安全水域可停靠，沿盆缘分段下潜；深海泊位不是免压罩 | 材料、结构、玻璃和舱口等薄弱部位的耐压 |
| 小体积主线：冰川区域 | 外围海床80～140格；关键冰下通道和目标约80～120格 | 外围20～40格深处设母艇停泊水域，小艇从过渡层下潜进入核心通道 | 通道净宽、净高、艇长和转弯包络，不能只比较总体积 |
| 补给与休整岛 | 港湾约20～40格，外侧自然接入安全水层 | 港口入口与母艇净空匹配；浅岸留给小艇接驳 | 不增加通行门槛 |
| 工业与打捞支线岛 | 岸上设施与20～60格浅水残骸为主；可选深处目标60～100格 | 基础支线无需深潜升级，深处额外收益明确提示 | 作业和资源回收，不强制叠加主线压力锁 |
| 异常与挑战支线岛 | 岸上及30～60格安全抵达点；挑战核心可在80～140格 | 公共航路只显示可选入口；主动进入隔离挑战区才触发战斗 | 独立探索或战斗，可绕过 |

表中的“任务深度”是内容布点范围，不是整艘艇体的最深处。主艇抵达点与每条通道均要按整艇外形复核，上表的普通外海海床也不能用于截断公共航路。

## 避免三个主线互相抢占考验

**速度区域：可以从上面经过，但不能从上面完成。** 主线目标位于深层流道内部，任务需要实际通过核心航段并作业。安全层可用于观察与绕过整个地区，不放置能在上方直接触发完成的任务点。具体核心入口和环境约束另行设计，避免用地图上的一条流带假装挡住所有路线。

**深海区域：向下才进入压力挑战。** 经过其上方不要求高级耐压船。深海资源、任务与Boss放在相应深度，盆缘提供渐进式探索机会，不能让首次下潜立即跨过多个耐压等级。

**冰川区域：外围能走大艇，内部必须小艇。** 冰山可以自然伸入浅水，但必须有宽阔外围绕行通道，不能用横贯整个地区的冰墙或密集冰山堵死安全层。关键小体积路线位于深部冰体和冰下腔室内部，顶板、侧壁及入口共同形成空间约束；通道上方的公共航路不能直接开口通向主线终点。如何处理玩家挖冰绕过考验，另设交互规则，不在这里擅自规定所有冰不可破坏。

建议初期通用船壳的正常工作耐压能力能覆盖速度区与冰川核心所需深度，暂以**140格级别**作为配套讨论基准，并为艇底留余量。具体材料值尚未确认；目的在于避免玩家做速度或小体积主线时，被迫先完成深海耐压升级。不能将“冰川很冷”自动变成另一个必须升级的低温锁。

## 与现有地图及实现的关系

- [地图分布方案](首个公开版地图布局-public-release-map-layout.md)中的约10分钟到首个区域、20～30分钟到边界，按安全航行层中的水平航程计算；下潜、核心通行、停靠及战斗单独计时。
- 范围外的同类区域采用相同安全层与深度逻辑，只剥离主线内容，不在10000格正方形边界突然改变水深规则。
- 本方案作为首个公开版的深度提案，替代旧草案0～480格路线的首版参考；旧文保留为后续扩展素材。它尚未成为已实现配置。
- 2026-10-16用户确认并要求实际调整：海面基准Y=128、世界最低Y=-256；最高可放置方块仍为Y=319，总高度576格。260格深处对应Y=-132，距世界底部仍有124格，可用于后续深海地形设计。
- 起始岛建设存档整体上移65格，现有建设海床仍保持原有相对水深，主要外海床面为Y=20；扩大世界高度不会自动生成深海盆地。区域深度、安全层、压力阈值仍属于待实现的玩法方案，不能把高度配置完成视为三个主线地区已经生成。
- 本次高度迁移验收只检查载入、建筑、潜艇与世界生成，不恢复此前已停止的巡航速度测试。迁移与运行入口见[世界高度与旧岛迁移](../development/世界高度与旧岛迁移-world-height-migration.md)。
