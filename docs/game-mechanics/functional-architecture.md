# 整合包功能架构

核心循环为：建造潜艇 → 远航勘探 → 离艇探索 → 获取资源与技术 → 改装潜艇 → 挑战更深、更危险的海域。

潜艇同时承担移动基地、运输工具和探索平台的作用。内容围绕出航目标、升级收益和新的探索发现组织，具体海域准入规则见[海域准入与潜艇能力限制](ocean-access-gates.md)。

## 功能模块

| 模块 | 功能需求 | 玩法作用 |
| --- | --- | --- |
| 海洋世界 | 海洋占主导、稀少大陆、连通深海、海沟海盆、海山群岛、安全出生区 | 为大型潜艇提供航行空间 |
| 海域分层 | 浅海、深海、深渊；不同温度、能见度、资源和危险等级 | 形成探索进度与区域辨识度 |
| 自由造船 | 方块拼装、装配拆解、质量浮力重心、建造辅助与状态检查 | 让船型和布局影响使用体验 |
| 潜艇航行 | 潜浮、压载、推进、转向、稳定、悬停、驾驶仪表 | 建立可靠的水下操控体验 |
| 舱室与生命保障 | 密封检测、供氧、排水、舱门气闸、舱室隔离、漏水报警 | 形成安全生活区与损管玩法 |
| 船载能源 | 生产、储存、配电、耗能、续航估算、备用电源、燃料补给 | 让航程与设备配置成为选择 |
| 导航与探测 | 地图、航标、测深、障碍预警、目标探测、探索记录 | 支持低能见度航行并提供探索线索 |
| 海洋生态 | 分区鱼群、捕食者、大型生物、发光生物、采集植物、稀有物种 | 让海洋具备生活感与资源差异 |
| 遗迹与探险 | 沉船、废弃设施、洞穴、异常信号、谜题、日志和奖励 | 提供停船与离艇探索的目的地 |
| 资源与工业 | 采矿、采集、打捞、加工、零件制造、资源替代和再生 | 支撑海洋世界中的完整生存与升级流程 |
| 离艇潜水 | 装备、氧气、照明、工具、防护、短程推进、返航标记 | 进入潜艇无法抵达的空间 |
| 战斗与 Boss | 普通威胁、区域精英、Boss 阶段、攻击预警和撤退空间 | 提供挑战与升级目标 |
| 损伤与救援 | 碰撞、破损、进水、维修、求救信标、定位与打捞 | 让事故有代价，也有恢复机会 |
| 船内生活与后勤 | 仓储、厨房、休息区、加工、物资统计、装卸和补给清单 | 支持长期远航与移动基地生活 |
| 港口与基地 | 停泊、维修、充能、交易、船坞、海底前哨和航标网络 | 建立航行的出发点和中途支撑 |
| 任务与成长 | 建造教学、探索委托、技术解锁、图鉴、日志和阶段目标 | 串联分散内容，引导学习机制 |
| 氛围表现 | 深度光照、水色、舱内外声音、机械声、海怪声与环境音乐 | 营造探索感与深海压迫感 |
| 运行与维护 | 大船性能、实体数量、生成优化、备份、权限和多人同步 | 支撑长期稳定游玩 |

## 成长阶段

| 阶段 | 主要活动 | 新能力 |
| --- | --- | --- |
| 海岸求生 | 建立补给点，探索浅海沉船，收集材料 | 基础潜水与短途航行 |
| 首次潜航 | 建造小艇，掌握密封、能源与潜浮 | 常规深海与短期远征 |
| 远洋生活 | 扩建生活和加工舱，建立港口网络 | 长距离航行与更高自给能力 |
| 深渊探索 | 升级耐压、探测与损管，调查危险遗迹 | 极深海域、特殊材料与技术 |
| 巨艇远征 | 建造综合母艇，组织多人分工，挑战终局区域 | 长途远征与大型 Boss 挑战 |

## 设计约束

- 以预计潜艇的长、宽、高和转弯需求反推水深、海沟宽度、港口入口与停泊区，不预先锁死世界尺寸。
- 升级逐步开放照明、探测、续航、损管与深潜能力，避免只增加数值和材料需求。
- 广阔海域用于驾驶，狭窄遗迹用于子艇或潜水；离艇入口附近应有合理停泊位置。
- 水压、能源不足、漏水和大型生物接近需要可理解的预警，避免无预警毁船。
- Boss 可采用离艇战斗、驾驶规避、设施保护和潜艇协同作战；船体攻击与损伤交互需要单独验证。
- 木材、食物、基础金属、燃料和关键材料在海洋世界中都要有可获得渠道。解锁材料不能全部藏在只有解锁后才能进入的区域。

## 建设顺序

第一轮完成海洋地形、造船、航行、密封供氧、能源、导航、加工、潜水和少量遗迹，让一次完整远航成立。

第二轮加入速度、压力、尺寸和续航限制，扩展深度分区、损管、生态与任务。最后再增加巨型 Boss、复杂海流、高级自动化和额外环境限制。
