## 状态与维护规则

- **已确认目标**：用户确认的设计方向或指标，仍需单独注明是否实现和验收。
- **原型配置**：已写入代码或资源，不代表平衡定稿，也不保证与最终伤害、实际航速相同。
- **待定方案**：待确认和验证，不能直接覆盖现有配置。
- **历史记录**：保留溯源，不以旧海试结果推断当前版本性能。

整体初案与深度方案以本目录中的文件为维护正文。跨主题开发文档保留原位并建立索引，不复制成另一套长期维护的配置。

运行时来源仍为 `mods/dbv-world/src/main/resources/dbv_prototypes.json`、掉落表及代码；完整设计规格仍在 `content/prototypes/`，避免移动后破坏设计器、生成器和便携工具。修改原型规格后需重新生成资源，并同步本目录数值快照及核对版本。不要直接修改本目录的表格就宣称游戏数值已更新。
