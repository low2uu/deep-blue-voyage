## 数值口径

- 潜艇深度采用控制器世界坐标：`D=当地海面Y−控制器世界Y`，当前海面基准128；不是实体包围盒顶部。艇底及外设仍需独立验收。
- 原型怪物生命以生命点计；玩家20点为10颗心。移动速度属性不是实测格/秒，攻击属性也不等于所有AI技能的实际扣血。
- 草案武器DPS为未减伤、命中时的纸面输出；装备后扣血目标、原始伤害、设备耐久、方块硬度、爆炸抗性和材料耐深分开记录。
- 物理质量为Sable单位，不能当公斤；升降速度配置单位格/tick，与4格/秒的水平航速目标不同。
- 声呐距离、耐压与氧气目标属于整艇验收指标；不能只升级外壳而忽略玻璃、门与设备。

## 重点待定与差异

| 事项 | 现有方案 | 仍需确认或实现 |
| --- | --- | --- |
| 安全水层 | 0～60格，常用巡航20～35格 | 上下界未确认；不是全局免伤区 |
| 航速升级 | 4 / 5.5 / 7格/秒 | 只有初期4已确认；满载工况与实测待做 |
| 壳材等级 / 任务深度 | 140/220/300格；120/190/260格 | 全部待定；不得直接覆盖现有材料耐压 |
| 续航 / 应急氧气 | 45/65/90分钟；两人5/8/12分钟 | 实际燃耗、舱体体积与储量未定 |
| 洋流 | 1/3/4.5/6格/秒 | 物理接入、横流和避流路线待验证 |
| 小艇 / 通道 | 15×7×7；净宽高11；转弯室32×32 | 全部待定，须包含外设与转弯包络 |
| Boss生命 | 目标1800/2800/1200，原型均1024 | 当前原型受上限约束；不能用1024覆盖目标 |

| 武器、维修和研究物品 | 已注册物品与外观 | 发射、维修效果、研究解锁尚未实现 |

完整武器、设备耐久、Boss战斗时长、补给和材料比例见[整体初案](整体玩法与数值初案-gameplay-and-balance-draft.md)，不在此重新定义。旧七海域、0～480格深度、24座支线岛与已撤销的物理调参不能自动计入当前正式规则。
